# 公理 IV：对应公理 (Axiom of Correspondence)

**——变分型泛函对应原理：极限还原与重整化**

---

## 形式化陈述

公理 I 管"是什么"，公理 II 管"怎么变"，公理 III 管"多确定"。本公理补上缺失的一环：**新旧理论之间如何过渡**——即玻尔**对应原理**（correspondence principle）的数学化。

**概念区分。** 对应原理 = **极限还原**（新描述在极限下还原为旧描述）；互补原理 = **同时互斥**（如波与粒不能同时完整观测）。本公理属前者。

**符号约定。** 下述 X 为拓扑空间（如平方可积函数空间，或概率测度空间配弱星拓扑）；Λ 为指标集，λ₀ 为其极限点；泛函族记为 F_λ，取值于扩展实数集。**等度强制**指：对任意实数 t，集合族的并集 {F_λ ≤ t}（λ 遍历 Λ）在 X 的拓扑下相对紧；通常另设每个 F_λ 在 X 上下半连续，以保证其极小元存在。

**公理 IV（对应公理，变分型）。** 设泛函族 F_λ（λ 趋于 λ₀）在 **Γ-拓扑**下收敛于极限泛函，且等度强制，则**变分还原**无条件成立：

$$\min F_{\lambda}\ \longrightarrow\ \min F_{\lambda_0}$$

并且极小化序列存在弱收敛子列，其极限是极限泛函的极小元。

**附加条款（非无条件）。** 在额外条件（Mosco 收敛、一致椭圆性、紧嵌入等，见第三节）下，另有**谱还原**与**精度还原**（逐模还原；总量 γ 迹发散）：

$$\lambda_k^{(\lambda)}\ \longrightarrow\ \lambda_k^{(\lambda_0)},\qquad \gamma=\sum_k\lambda_k$$

**范围限定。** 本公理仅覆盖**变分型（能量极小型）**对应原理。代数型对应（对易子极限、Weyl 与 Moyal 星积、非交换到交换的算子代数）**不在本公理内**。

---

## 一、Γ-收敛：极限还原的骨架

**定义（Γ-收敛，De Giorgi）。** 一族泛函在 Γ-意义下收敛，当且仅当以下两条同时成立：

- （下极限）对任意极限点，及任意逼近它的序列，极限泛函的取值不超过该序列取值的下极限；
- （恢复序列）对任意极限点，存在逼近它的序列，使极限泛函的取值不小于该序列取值的上极限。

**定理（变分收敛）。** 若一簇泛函在 Γ-意义下收敛且等度强制，则其极小值收敛，且极小元的聚点是极限泛函的极小元。

> 注意：Γ-收敛是**能量泛函的变分收敛**，结论**止于变分层**，**不含**二阶（谱）信息。

**对易子极限（属代数型，非本公理）。** 对应原理的代数形式须写成极限：

$$\frac{1}{i\hbar}\,[\hat A,\hat B]\ \longrightarrow\ \{A,B\}_{\mathrm{Poisson}}\qquad(\hbar\to0)$$

---

## 二、实例

### 2.1 离散 → 连续（Γ-收敛直接实例）

网格泛函收敛到连续泛函；图拉普拉斯收敛到连续拉普拉斯。见第三节引理 A、B。

### 2.2 多体 → 平均场（Γ-收敛直接实例）

以 N 个粒子的**经验测度**为状态变量：核**有界**时见引理 C；核**无界**（Coulomb / Riesz）时见引理 D。

### 2.3 量子 → 经典（半经典对应，非 Γ-收敛）

$$\int \mathcal{D}\psi\;e^{\,iS[\psi]/\hbar}\ \longrightarrow\ \delta S=0\qquad(\hbar\to0)$$

这是**驻相法 / 半经典分析**（振荡积分本身不收敛），须经 Wick 旋转方可纳入变分框架，故单列。

## 三、可证引理

### 引理 A（离散 Dirichlet 能量的 Γ-收敛）

设网格间距为 h=1/n，取 Dirichlet 零边界条件 u_0 = u_n = 0（连续极限下即 u(0)=u(1)=0）。离散泛函

$$F_n(u)=\frac{1}{h}\sum_{i=0}^{n-1}(u_{i+1}-u_i)^2+h\sum_{i=1}^{n-1}(f_i-u_i)^2$$

的 Γ-极限为

$$F(u)=\int_0^1\Big[(u')^2+(f-u)^2\Big]\,dx$$

于是极小值收敛，极小化序列弱收敛到一维 Helmholtz（屏蔽 Poisson）问题 $`-u''+u=f`$ 之解。

### 引理 B（谱还原，需附加条件）

离散 Dirichlet Laplacian 的特征值为

$$\lambda_k^{(n)}=4n^2\sin^2\frac{k\pi}{2n},\qquad k=1,\dots,n-1$$

固定 k 时，它收敛到对应连续算子的特征值 π²k²（谱，逐模收敛）。此结论依赖一维显式可解性；一般情形需附加条件（Mosco 收敛、一致椭圆性、紧性等）。

> **曲率（精度）提醒。** 这里 $`L_n`$ 指离散 Dirichlet Laplacian：$`L_n=A/h^2`$，$`A`$ 为三对角矩阵 $`[2,-1;-1,2]`$（$`h=1/n`$）。其迹（即总曲率）满足

$$\gamma_n=\mathrm{Tr}(L_n)=\mathrm{Tr}(A)/h^2 \;\sim\; 2n^3\to\infty$$

即在自由度趋于无穷时发散。

> **缩放提醒（Hessian 与 Laplacian 相差 2h）。** 引理 A 的 Γ-收敛能源 $`F_n=\frac{1}{h}\sum_i (u_{i+1}-u_i)^2`$ 的 Hessian 是 $`\frac{2}{h}A=2h\,L_n`$：其迹为 $`4n^2`$，逐模特征值 $`8n\sin^2\frac{k\pi}{2n}\to 0`$；而谱收敛的 $`L_n`$ 特征值为 $`4n^2\sin^2\frac{k\pi}{2n}\to k^2\pi^2`$。二者相差 $`2h=2/n`$ 倍——**离散拉普拉斯 $`L_n`$ 并非 Γ-收敛能源 $`F_n`$ 的 Hessian**，这正是"仅 Γ-收敛得不到谱收敛、需 Mosco 收敛"的具体根源。无论取何种口径，$`\gamma_n`$ 均发散，**只能逐模还原**（总量"按自由度归一化"不收敛：$`4n^2/n=4n`$、$`2n^3/n=2n^2`$ 仍发散）。

### 引理 C（平均场能量的 Γ-收敛，核有界）

**条件。** 状态空间取紧集，或势 V 满足增长条件（如趋向无穷），以保证经验测度序列弱紧（即等度强制）。

经验测度与粒子能量为

$$\mu_N=\frac{1}{N}\sum_{i=1}^N\delta_{x_i},\qquad E_N=E(\mu_N)=\frac{1}{2N^2}\sum_{i,j}W(x_i-x_j)+\frac{1}{N}\sum_i V(x_i)$$

平均场泛函为

$$E(\mu)=\frac{1}{2}\iint W(x-y)\,d\mu\,d\mu+\int V\,d\mu$$

当核有界连续时，粒子能量的 Γ-极限为平均场泛函。证明：泛函弱星连续、对角项 W(0)/(2N) 趋于零、概率测度空间弱星紧（Prokhorov）且经验测度弱星稠密。

### 引理 D（Coulomb / Riesz 平均场能量的 Γ-收敛，核无界）

**条件。** 同引理 C：状态空间紧或势 V 满足增长条件（保证弱紧与等度强制）。

设 Riesz 核，指标 s 介于 0 与 d 之间。**排除对角**后，粒子能量与平均场泛函为

$$E_N=\frac{1}{2N^2}\sum_{i\neq j}|x_i-x_j|^{-s}+\frac{1}{N}\sum_i V(x_i)$$

$$E(\mu)=\frac{1}{2}\iint|x-y|^{-s}\,d\mu\,d\mu+\int V\,d\mu\ \in(0,+\infty]$$

后者是**扩展值泛函**（允许取正无穷）。则粒子能量的 Γ-极限为平均场泛函。与引理 C 的两处差别：

1. **下极限——上方截断 + 单调收敛**：先用有界截断核套用引理 C，再令截断参数趋于零，由单调收敛还原。
2. **上极限——正则化 + 经验测度构造 + 标度条件**：先用正则化使能量不增；再构造间隔为 δ 的 N 个点，其近对角自能满足

$$\frac{\delta^{-s}}{N}\ \longrightarrow\ 0\qquad\Longleftrightarrow\qquad N\,\delta^{\,s}\ \longrightarrow\ \infty$$

只要 s 小于 d 即可满足（例如取 δ 为 N 的负 1/d 次幂）。

## 四、重整化：极限 − 发散的无穷 = 有限余项

### 4.1 动机

引理 C 与 D 只给出**主导阶**（极限是什么）。但能量本身发散；重整化刻画其**发散结构 + 有限余项**。

### 4.2 精确展开（2D Coulomb 气体）

设 2D Coulomb 气体的能量为

$$H_N=-\sum_{i\neq j}\log|x_i-x_j|+N\sum_i V(x_i)$$

平衡测度 μ₀ 极小化宏观能量。则（Sandier–Serfaty, 2015, 式 (1.19)）能量精确拆为

$$H_N=N^2 I(\mu_0)-\frac{N}{2}\log N+\frac{1}{\pi}W(\nabla H_N',\mathbf 1_{\mathbb R^2})+2N\int\zeta\,d\nu_N$$

其中 H_N' 为放大坐标下的电场（原文式 (1.20)），ζ 在平衡测度支撑上为零。右端**末两项合起来**为阶为 N 的重整化余项；把它对 N 归一化，即得平均重整化能量。故与下述**粗形式**一致：

$$H_N=N^2 I(\mu_0)-\frac{N}{2}\log N+N\,\overline{W}+o(N),\qquad \overline{W}=O(1)$$

于是核心关系是

$$H_N-\Big(N^2 I(\mu_0)-\frac{N}{2}\log N\Big)=N\,\overline{W}+o(N)$$

即"极限 − 发散的无穷 = 有限（对 N 归一化后）余项"。

### 4.3 重整化能量的定义（显式减发散）

$$W(E,\chi)=\lim_{\eta\to0}\left(\frac{1}{2}\int_{\mathbb R^2\setminus\cup_p B(p,\eta)}\chi\,|E|^2+\pi\log\eta\sum_p\chi(p)\right)$$

约束为电场的散度等于电荷密度、旋度为零。其中被加上的对数项**正是被减去的发散**；减去后极限存在且有限。其全局版为局域值按区域的渐进平均。

### 4.4 一般范式

$$\Phi(\varepsilon)=\sum_k c_k\,\varepsilon^{-\alpha_k}+\Phi_{\mathrm{ren}},\qquad \alpha_1>\alpha_2>\cdots>0$$

其中前一项随截断发散，后一项与截断无关（有限，即重整化不变量）。同型结构出现在：量子场论（质量与电荷重整化）、Coulomb 气体（W）、奇异极限的偏微分方程、Fekete 点。**核心动作**：减去尺度相关的无穷，剩下的才是与截断无关的不变量。

## 五、与公理 I / II / III 的接口

- **公理 II（演化）**：本公理是"变分问题在泛函族层面的元定理"——极小值与极小元随极限还原。
- **公理 III（精度）**：附加条款给出曲率的逐模还原；且迹（总曲率）在连续极限发散、须归一化——**归一化正是重整化的同一动作**。
- **高阶形态**：主导阶给出"还原到哪个泛函"；高阶给出"发散的层级 + 截断无关的余项"。

一句话：三公理描述**单个泛函**；公理 IV 描述**泛函族之间的过渡**。

## 六、与互补原理的区分

| | 对应原理 | 互补原理 |
| :--- | :--- | :--- |
| 机制 | 极限还原 | 同时互斥 |
| 关系 | 新描述在极限下还原为旧描述 | 波与粒不能同时完整观测 |
| 本框架归属 | 公理 IV | 不在本公理内（观测层面） |

## 七、范围、定位与待办

1. **范围**：变分型对应原理；代数型另列。
2. **定位**：公理模式 / 元定理（其具体实例引理 A–D 是可证定理）。
3. **拓扑必须指定**：Γ-收敛。
4. **等度强制不可省**：缺之则极小值可不收敛。
5. **谱还原有前提**；曲率需归一化。
6. **无界核的额外条件**：指标 s 小于 d 时，标度条件可满足。
7. **代数型对应的去留**：对易子极限、Weyl 与 Moyal 星积、非交换到交换的算子代数**已明确排除**；不在本条内，另案拟立公理 V「代数型对应」（待撰）。
8. **编号与引用格式**：纳入 axioms/ 后，须与公理 I–III 统一（文件名建议 axiom_IV_correspondence.md）。
9. **避免空泛**：每条对应须落到"极限 / 拓扑 / 还原目标"三元组。
