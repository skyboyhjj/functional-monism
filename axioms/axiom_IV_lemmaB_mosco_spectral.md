# 引理 B 补注：从 Γ-收敛到谱收敛——Mosco 补了什么

**——顺着"2h"这条线，回答"为什么加 Mosco 就够了"**

---

## 0. 问题的提出

引理 A 给出 **Γ-收敛**（变分还原）：

$$F_n\ \longrightarrow\ F,\qquad F(u)=\int_0^1\big[(u')^2+(f-u)^2\big]\,dx$$

引理 B 给出 **谱收敛**（离散 Dirichlet Laplacian 的特征值）：对固定 k，

$$\lambda_k^{(n)}=4n^2\sin^2\frac{k\pi}{2n}\ \longrightarrow\ \pi^2k^2$$

**问题**：这两件事之间缺了什么？为什么前者"推不出"后者，而补上 **Mosco 收敛**就够了？

---

## 1. "2h"事实：谱收敛的算子 ≠ Γ-收敛能源的 Hessian

记离散 Dirichlet Laplacian 为 L_n = A/h²，其中 A 是三对角矩阵（对角 2、次对角 −1），h=1/n。引理 A 的能量是

$$F_n(u)=\frac{1}{h}\sum_{i=0}^{n-1}(u_{i+1}-u_i)^2$$

它的 Hessian（对坐标 u_i 的二阶偏导矩阵）是

$$\mathrm{Hess}(F_n)=\frac{2}{h}A=2h\,L_n\ \ne\ L_n$$

**关键：谱收敛到 −Δ 的算子是 L_n，而 Γ-收敛能源 F_n 的 Hessian 是 2h·L_n——两者相差因子 2h。** 后果是：

| 算子 | 第 k 个特征值 | 极限 |
| :--- | :--- | :--- |
| L_n（谱收敛的那个） | 4n²sin²(kπ/2n) | π²k²（有限） |
| 2h·L_n = Hess(F_n) | 8n·sin²(kπ/2n) | 0 |
| 2h·L_n 的最大特征值 | ≈8n(1−O(1/n²))（渐近） | ∞ |

也就是说，**Hess(F_n) 的谱没有极限算子**：低模塌到 0、上限发散。要得到漂亮的谱收敛，必须**除以因子 2h**——而这一步"重整化"，**Γ-收敛并不提供**。

一个等价的说法更直接：Γ-极限 F 的**二阶变分**是 2(−Δ+I)（特征值 2(π²k²+1)，非零、增长）；而 F_n 的二阶变分 Hess(F_n) 的低模特征值趋于 0。**二阶变分根本不收敛**——可 Γ-收敛照样成立。这就是"Γ 推不出谱"的标本。

---

## 2. 三级收敛：值 → 形 → 谱

把三种收敛的层级摆清楚（X 为自反 Banach 空间，泛函取值于扩展实数集）：

**（1）Γ-收敛（值级）。** 对任意 x_n 强收敛到 x，有 F(x) ≤ liminf F_n(x_n)；且对任意 x，存在 x_n 强收敛到 x 使 F(x) ≥ limsup F_n(x_n)。
→ 只保证 **极小值 / 极小元** 收敛。

**（2）Mosco 收敛（形级）。** 把上面"liminf 一侧"的强收敛换成**弱**收敛，其余不变。
→ 对二次泛函，等价于 **算子（预解）级** 收敛。

**（3）强预解收敛（算子级）。** (A_n − z)⁻¹ 强收敛到 (A − z)⁻¹。
→ （紧预解下）**谱** 逐点收敛。

**关系链**：

$$\text{Mosco}\ \subset\ \Gamma;\qquad \text{Mosco}\ \Longleftrightarrow\ \text{resolvent}\ \Longrightarrow\ \text{spectrum}\quad(\text{+ compactness})$$

**一句话：Γ 管"值"，Mosco 管"形"，而谱是"形"的属性——所以要 Mosco。**

---

## 3. 定理：二次泛函下，Mosco = 强预解

**定理（Mosco 1969；综述见 Attouch 1984、Dal Maso 1993）。** 设 a_n, a 是 Hilbert 空间上闭的、对称、强制的双线性形，对应自伴算子 A_n, A。则

$$a_n \longrightarrow a\ (\text{Mosco})\qquad\Longleftrightarrow\qquad A_n^{-1}\longrightarrow A^{-1}\ (\text{strong})$$

**推论（谱）。** 若 A_n 的预解算子**紧**且"集体紧"（collectively compact：集合 {(A_n−z)⁻¹x : ∥x∥≤1，n 任意} 相对紧），则特征值逐点收敛：λ_k(A_n) → λ_k(A)。

（本离散情形中，A_n 有限维，预解本就紧，故条件自动满足。）

---

## 4. 为什么 Γ 不够

Γ-收敛只比较**标量值** F_n(x_n)。它先天看不见"算子"，也看不见"二阶变分"：

- 由第 1 节，F_n 与 F 的**二阶变分都不收敛**（一个塌到 0、一个增长），但 Γ-收敛成立；
- 原因：能量里的 1/h 前因子，**既让"值"收敛**（F_n → ∫(u')²），**又把 Hessian 缩放成 2h·L_n**——这个因子对"值"无害，却把"谱"抹掉了；
- 所以 **F_n Γ-收敛到 F** 完全兼容"Hess(F_n) 无极限算子"。

**结论**：谱的信息，藏在 Γ-收敛看不见的"归一化 / 二次形结构"里。Γ 是"值级"的，先天看不见"形"。

> **术语关联。** 第 1 节"除以 2h"这一步"归一化"，正是公理 IV 第 4 节"重整化"的同一动作。

---

## 5. 为什么 Mosco 就够了

Mosco 把比较从"值"升到"**弱序列下的双线性形**"：它要求 a_n(u_n, v_n) 对 u_n 弱收敛到 u、v_n 弱收敛到 v 时，表现得像 a(u, v)。这恰好是"识别算子"所需的强度——

- 由第 3 节定理，它**等价于预解收敛**；
- 预解收敛是谱收敛的**标准充分条件**；
- 在本例，能量形 a_n 经分片线性延拓到 L²(0,1) 后 Mosco 收敛到 a(u,u) = ∫(u')²，于是 (L_n + I)⁻¹ 强收敛到 (−Δ + I)⁻¹；两侧预解都紧，特征值逐点收敛：

$$\lambda_k(L_n)\ \longrightarrow\ \pi^2k^2=\lambda_k(-\Delta)$$

这正是引理 B。

> **技术注（质量矩阵 M_n）。** 第 1 节"除以 2h"以及"从刚度到拉普拉斯"的换算，都可归结为"除以质量矩阵"。能量形 a_n 的刚度矩阵为 K_n = A/h；离散 Dirichlet Laplacian 是 K_n 除以 L² 质量尺度 h 所得：K_n/h = A/h² = L_n。而 Hess(F_n) = 2K_n 未做此归一化（即未除 M_n ≈ h·I），故相对 L_n 多出因子 2h。

---

## 6. 小结与一个反面例子

**小结。**

- **"2h"是一个可手算的例证**：Γ-收敛能源的 Hessian 是 2h·L_n，它的谱退化；谱收敛属于"另一个"算子 L_n。二者只差一个"重整化因子"，而 Γ-收敛对这个因子"无感"。
- **Γ 管值，Mosco 管形**；谱是形的属性。
- **Mosco 之所以够**：对二次泛函，Mosco 收敛**等价于强预解收敛**（Mosco 定理），而预解收敛正是谱收敛的标准入口（紧预解下给出特征值收敛）。
- 所以引理 B 的正确前提不是"再多加点 Γ-收敛"，而是"**升到 Mosco（等价地，算子 / 预解级）**"。

**一个反面例子（说明"Γ 不够"不是本例的巧合）。** 均匀化：取 a_n(u,u) = ∫ A(x/ε_n)|u'|²，它在 Γ-意义下收敛到均匀化能量 ∫ A*|u'|²（A* 为调和平均）。此时一致椭圆二次形的 Γ-收敛只给出**弱预解收敛**（G-收敛），故仅**低阶特征值**逐点收敛到均匀化算子的特征值，而**高频谱结构（态密度、带隙）并不收敛到均匀化算子的对应结构**——谱的高频部分仍"看得见"微观结构。可见"Γ 收敛而（整体）谱不收敛"是普遍现象，不是偶然。

| Mosco（形级） | 弱序列下的双线性形 | 算子 / 预解收敛 | 关键桥梁 |
