# 旋量与泛函一元论的接口

**——三层关系：包含 / 共同语言 / 主题呼应**

---

## 〇、方法：先立规矩

本笔记把"旋量"与"泛函一元论"的关系，按**强度**分三层陈述，**绝不把主题呼应冒充等价**：

- **硬（包含）**：旋量动力学**本身**就是公理 II 的实例——可写成变分、可推出方程。这是**包含关系**（Dirac 场属于公理 II 的实例集）。
- **半硬（共同语言 / 形式化观察）**：复结构、对称性、精度 γ——有形式依据，部分待夯实。
- **主题（呼应）**：非物性、二元结构——只是"同构感"，**必须显式标注，不可当定理**。

---

## 一、硬联系：Dirac 场是公理 II 的一个实例

设 ψ 为 Dirac 旋量场（取值于自旋群的表示空间），Dirac 拉氏密度

$$\mathcal L_D=\bar\psi\,(i\gamma^\mu\partial_\mu-m)\,\psi$$

空间积分给出泛函一元论里的"泛函" F = ∫L_D dx，作用量为 S = ∫F dt = ∫∫L_D dxdt。

**对 ψ̄ 变分**，得 Euler–Lagrange 方程：

$$\frac{\delta S}{\delta\bar\psi}=0\ \Longrightarrow\ (i\gamma^\mu\partial_\mu-m)\,\psi=0$$

即 **Dirac 方程**。

对照公理 II（$\delta\int F[\psi]\,dt=0$）：

> **ψ = 场构型，F = Dirac 拉氏量。旋量场是公理 II 的直接实例，不是类比。**

而且公理 II 推论 4 的路径积分 $\int\mathcal D\psi\,e^{iS/\hbar}$，对旋量而言，其中的测度是 **Grassmann 场的 Berezin 积分**——旋量正是该积分"天然要的" ψ。

## 二、半硬层：共同语言与形式化观察

### 2.1 都以"复 + 相位"为底

| | 旋量 | 泛函一元论 |
| :--- | :--- | :--- |
| 基本对象 | ψ ∈ ℂ² | 复值泛函 F: H → ℂ |
| 核心自由度 | 相位 e^{iθ} | 相位 e^{iS/ℏ} |

两者都赌同一件事：**"存在"的最底层是复的，相位是核心自由度。**

### 2.2 对称性：旋量是"ψ"的最小自洽取法

泛函一元论说"一切是 F[ψ]"，却**没说 ψ 长什么样**。旋量回答了一半：ψ 应携带**对称群的表示**；在有自旋的世界里，这个群是自旋群 Spin(3) / Spin(1,3)，而**旋量是它最小的非平凡表示**（自旋 ½）。

即：**旋量是"ψ"的一个有对称性根据的具体候选**——不是随便挑的复向量，而是**唯一**能承载"转 720° 归位"的那一个。

### 2.3 精度 γ 对旋量场 = Dirac 算子（形式化观察，待夯实）

公理 III：$\gamma=\big\|\delta^2F/\delta\psi^2\big\|_{S1}$。Dirac 作用量是 ψ 与 ψ̄ 的**双线性型**（对单一 ψ 线性），故

$$\frac{\delta^2 S_{\mathrm{Dirac}}}{\delta\bar\psi\,\delta\psi}=i\gamma^\mu\partial_\mu-m\quad(\text{Dirac operator})$$

> **形式化观察**：对有自旋的场，"精度 / 曲率"γ 就是**狄拉克算子的范数**。
> （**口径与标注**：公理 III 的 γ 用**纯二阶变分** $\delta^2F/\delta\psi^2$，而 Dirac 作用量对单一 ψ 线性、**纯二阶变分为零**，非零的只有**混合变分** $\delta^2 S/(\delta\bar\psi\,\delta\psi)=D$；严格化需把 $(\psi,\bar\psi)$ 合并为联立场，Hessian 取反对角块，此时 $\gamma\approx 2\|D\|$（而非 $\|D\|$），且 $D$ 非迹类、迹范数发散（与公理 IV"总曲率 γ 迹发散"自洽）。此外 ψ 为 Grassmann 量，此"二阶变分"是形式的，严格化仍需 Berezin 积分 / 超对称变分。**先记为待夯实，不当定理。**）

## 三、主题层：两处"呼应"——不可当等价

### 3.1 "基本实体不是物"的层级位移

旋量不是"指向某处的箭头"；泛函一元论的存在不是"物"。两者都把"最底层"从直觉中的物**挪走一层**。→ **主题呼应，非定理。**

### 3.2 二元结构：ℤ₂ 双覆盖 ↔ 两副面孔 / 两层

旋量有 360°→−、720°→+（**拓扑双值**，记作 ℤ₂）；泛函一元论有"量子 / 经典两副面孔""单泛函 / 泛函族两层"。

> **必须踩刹车**：一个是**拓扑双覆盖（ℤ₂）**，一个是**同一理论的两个极限 / 两个描述层级**——**结构不同，不可混同**。记为"**待精确化的呼应候选**"，绝不可写成等式。

## 六、一句判断

> **旋量是泛函一元论的"最小复实现"。** 泛函一元论说"存在即泛函"，把 ψ 留白；旋量回答的是——**当世界有自旋时，那个 ψ 只能是旋量**。前者是元框架，后者是它在"有自旋的那半边"的具体落点。

**两者关系一句话：不是"像"，是"一个包含了另一个"。** 公理 II 的变分框架**包含** Dirac 场作为实例（硬联系）；其余（复结构、对称性、曲率、双覆盖）是在这个包含关系之上的**层层加深**，其中"双覆盖 ↔ 两副面孔"**必须标为待精确化**。
