#### 1.3 信号 → 状态空间映射策略

公共数据集通常有 16-64 通道，需要降维到我们的 2D 状态空间：

```
                ┌──────────────────────────────┐
                │   EEG 原始信号 (N 通道 × T)    │
                └─────────────┬────────────────┘
                              ▼
                ┌──────────────────────────────┐
                │   频带分解 (Welch PSD)         │
                │   δ(1-4) θ(4-8) α(8-13)      │
                │   β(13-30) γ(30-45) Hz        │
                └─────────────┬────────────────┘
                              ▼
        ┌─────────────────────┴─────────────────────┐
        ▼                                             ▼
┌───────────────┐                           ┌───────────────┐
│  注意力轴      │                           │  情绪轴        │
│  (β+γ)/(α+θ)  │                           │  FAA =         │
│  额叶均值      │                           │  ln(R_α/L_α)   │
│  Fz, F3, F4   │                           │  F3 vs F4      │
└───────┬───────┘                           └───────┬───────┘
        └─────────────────────┬─────────────────────┘
                              ▼
                ┌──────────────────────────────┐
                │  2D 状态向量 (attn, emo)      │
                │  输入 FunctionalMonism 模型   │
                └──────────────────────────────┘
```

**注意力轴公式**：

```
attention = (P_β + P_γ) / (P_α + P_θ + ε)
```

其中 P_band 是额叶电极（F3, Fz, F4）在该频带的平均功率，ε = 1e-6 防止除零。

**情绪轴公式**（额叶 α 不对称，FAA）：

```
emotion = ln(P_α(F4) / P_α(F3))
```

- FAA > 0 → 积极/趋近情绪 → Equanimity 方向
- FAA < 0 → 消极/回避情绪 → Pain Discomfort 方向

### Phase 2：消费级设备集成

#### 2.1 设备对比

| 设备 | 通道数 | 采样率 | 价格 | 接口 | Python SDK | 推荐度 |
|:---|:---:|:---:|:---:|:---|:---|:---:|
| **Muse 2** | 4 EEG + PPG | 256 Hz | ~¥1,500 | BLE | **muselsl** | ⭐⭐⭐ |
| Muse S | 4 EEG + PPG | 256 Hz | ~¥2,000 | BLE | muselsl | ⭐⭐ |
| NeuroSky MindWave | 1 EEG | 512 Hz | ~¥600 | BLE | BrainFlow | ⭐ |
| OpenBCI Cyton | 8-16 | 250 Hz | ~¥5,000 | BLE/USB | BrainFlow | ⭐⭐⭐ |

**推荐 Muse 2**：性价比最高，4 通道 EEG 覆盖关键位置，Python 生态成熟（muselsl），冥想研究社区活跃。

#### 2.2 Muse 2 通道布局

```
         AF7 ●    ● AF8      ← 前额叶（注意力 / 情绪不对称）
              forehead
TP9 ●                         ← 左颞叶
                      ● TP10  ← 右颞叶
```

- **AF7/AF8**：前额叶，用于计算注意力指标和 FAA
- **TP9/TP10**：颞叶，用于辅助信号质量评估

#### 2.3 接口协议

```
Muse 2 硬件
    │
    │  Bluetooth Low Energy (BLE)
    │  GATT Profile: 0xFE8D (Muse Service)
    │  PPG: 0x273E0009  |  EEG: 0x273E000A
    │
    ▼
BlueMuse (Windows) / bleak (跨平台)
    │
    │  建立 BLE 连接，订阅数据流
    │
    ▼
muselsl (Python)
    │
    │  stream() → LSL (Lab Streaming Layer)
    │  record() → CSV
    │
    ▼
┌─────────────────────────────────────┐
│  src/calibration/muse_adapter.py    │
│  - 实时接收 LSL EEG 流              │
│  - 频带功率计算 (2s 滑动窗口)        │
│  - 状态映射 (attention, emotion)     │
│  - 注入 FunctionalMonism 模型       │
└─────────────────────────────────────┘
    │
    ▼
meditation_dashboard.py（实时显示）
```

#### 3.1 设备升级路径

#### 3.2 验证协议

```
被试招募 (N≥20)
    │
    ├─ 专家组 (N=10, 冥想经验 > 1000 小时)
    └─ 新手组 (N=10, 冥想经验 < 10 小时)
    │
    ▼
实验流程 (单次 30 分钟)
    ├─ 5 min: 静息态基线（睁眼/闭眼各 2.5 min）
    ├─ 20 min: 正念呼吸冥想
    └─ 5 min: 静息态恢复
    │
    ▼
数据分析
    ├─ 频带功率时程
    ├─ 状态空间轨迹
    ├─ 模型预测 vs 被试自评（每 5 min 报告状态）
    └─ 参数拟合 (γ, θ, σ 个体差异)
```
