## 2. 新增功能

### 2.1 2D 状态空间

| 维度 | 语义 | 范围 |
|:---|:---|:---|
| 轴 0（注意力） | 0 = 完全专注，正方向 = 注意力散乱 | \(\mathbb{R}\) |
| 轴 1（情绪/唤醒） | 0 = 平静，正方向 = 紧张/焦虑，负方向 = 平和 | \(\mathbb{R}\) |

**核心理念**：当状态空间至少为 2D 时，系统可以在多个吸引子之间"徘徊"——这正是走神（mind_wandering）的数学定义。

### 2.2 5 种子 2D 吸引子布局

| 种子 | 坐标 | 语义 |
|:---|:---|:---|
| Breath Focus | \((0, 0)\) | 平静原点：专注 + 平静 |
| Pain Discomfort | \((2, 1)\) | 身体不适区：散乱 + 紧张 |
| Pending Tasks | \((3, -1)\) | 焦虑区：散乱 + 焦虑 |
| Self Reflection | \((-2, 2)\) | 反思区：内省 + 高唤醒 |
| Equanimity | \((-1, -1.5)\) | 平和的另一极：内省 + 平和 |

### 2.3 增强 mind_wandering 检测

2D 模式下，mind_wandering 通过 3 种机制自然涌现：

1. **种子匹配**：Pain Discomfort 或 Pending Tasks 胜出 → mind_wandering
2. **快速切换**：最近两步种子不同 → 注意力漂移
3. **空间距离**：\|x\| > 2.5（注意力轴远离原点）→ 注意力散乱

### 2.4 2D 状态空间散点图

新增交互式 Plotly 散点图，展示：
- 状态在 2D 平面上的完整轨迹（按胜出种子着色）
- 5 个 ⭐ 吸引子标记 + 名称标签
- 起点（○）和终点（×）标记
- 坐标轴标尺：注意力 ← → 散乱，情绪 平和 ← → 紧张

### 2.5 冥想状态统计面板

2D 模式下新增右侧面板：
- 状态分布（breath_focus / mind_wandering / meta_awareness / redirect_attention）
- 平均连续驻留时间
- mind_wandering 涌现标记（✅ 已涌现 / ⚠️ 未出现）

### 2.6 1D/2D 模式切换

侧边栏「2D 状态空间」复选框：
- 启用（默认）：2D 模式，所有新功能激活
- 关闭：回退到经典 v0.2 1D 标量模式
