## 〇、一句话

原文那五条（**维度／拓扑／范畴／类型／动力学**）是**一把尺**：它量的不是"机制对不对"，而是"机制有没有**动到空间本身**"。

拿它量本项目那句问话 ——「**内稳态进入动力学**是否达到了**状态空间扩展**」—— **五条全不亮**，于是判为**停在"给定空间内变形"**：这正是**公理 II 缺口**的形式脸。

★ **收口处那句话要改口（v1.2）**：**「势整形定理」不是第五条（动力学标准）的判据** —— 它的准确层是**奖励／策略层**（"最优策略不变"）；它判的是"**是否只改了目标**"。而第五条的门槛是"**把 Φ 写进流**"（详见 §四）。

## 一、原文逐字：四类状态空间、八层谱系、五条标准

### 1.1 核心区分（不依赖分支）

> 原文 §1.4：**核心区分在于：状态空间本身是否变化** —— 是"给定空间内的变形"，还是"空间本身的变形"？

原文并强调：**这个区分不依赖于你选择哪种数学分支** —— 范畴论可做"给定空间内的变形"，变分贝叶斯也可做"空间本身的变形"。

### 1.2 四种状态空间（逐字）

| 类型 | 含义 | 谁在变化 |
| :-- | :-- | :-- |
| 环境状态空间 | 外部世界的状态集合 | 环境本身 |
| 系统内部状态空间 | 系统内部状态的集合 | 系统自身 |
| 建模者的假设空间 | 建模者考虑的所有可能模型的集合 | 建模者 |
| 模型空间或结构空间 | 模型结构本身的集合 | 模型 |

★ 原文紧接一句判语：**非参数贝叶斯、结构学习、发育机器人，往往扩展的是建模者的假设空间，而不一定是系统本身的状态空间**。

> ⟹ 对我们的落点：判"内稳态进入动力学"时，**先问扩展的是哪一个空间**（§四 已照此绑定）。

### 1.3 八层谱系（逐字）

原文：**"给定空间内的变形"与"空间本身的变形"不应被理解为二元对立，而应被理解为一个谱系** ——

| 层次 | 含义 | 状态空间是否变化 |
| :-- | :-- | :-- |
| 参数学习 | 状态空间固定，只更新参数 | 否 |
| 结构学习 | 模型结构变，但状态空间类型可能仍固定 | 部分 |
| 元学习 | 学习如何学习，学习算法的结构改变 | 部分 |
| 状态空间扩展 | 新维度、新模态、新边界生成 | 是 |
| 开放演化 | 演化过程本身改变系统的可能性空间 | 是 |
| 生态位构建 | 系统主动改变环境，从而改变自身的状态空间 | 是 |
| 发育与形态发生 | 系统形态本身在互动中生成 | 是 |
| 本体生成 | 什么算作"状态""边界""观察者"本身在互动中生成 | 是，且更深 |

★ **状态空间扩展只是这八层里的一格**（第 4 格）。本稿借它做"是否动到空间本身"的**最低门槛**；若要**分档**，原文这张谱系表就是现成的刻度尺。

### 1.4 五条形式标准（逐字）

> 判定"状态空间扩展"，原文给的五条**形式标准**：

| # | 标准 | 原文（逐字） |
| :-: | :-- | :-- |
| 1 | 维度标准 | 状态空间的维数是否增加（如从有限维到无穷维，或从固定维数到可变维数） |
| 2 | 拓扑标准 | 状态空间的拓扑性质是否改变（如连通性、紧致性、同胚类型的变化） |
| 3 | 范畴标准 | 描述状态空间的范畴是否更换（如从集合范畴到拓扑斯，或从固定范畴到可变范畴） |
| 4 | 类型标准 | 类型宇宙是否扩展（如同伦类型论中的类型层级是否增加） |
| 5 | 动力学标准 | 系统的吸引子结构、分岔模式、稳定性景观是否发生定性变化 |

★ 原文紧接一句，**是 v1.1 校订的关键**：

> 这些标准**不是互相排斥**的，而是**从不同角度**刻画"状态空间本身变化"。

⟹ **五条是并列视角，不是层级**。

> ★ **约定（v1.2）**：本稿把"**命中一条即算动到空间本身**"作为操作**约定** —— 原文只说五条**不是互相排斥、从不同角度**，**未给阈值规则**。

### 1.5 原文自己就用了这把尺

原文拿五条标准逐层判定：**变分贝叶斯／路径积分／NESS／贝叶斯力学／范畴论进路，均"不满足任何一条"**；结论是：FEP 标准表述预设固定状态空间，"不是'倾向于'，而是其数学结构本身"。

★ 原文另给了一个**伪通过判例**（§1.3）：Friston 与合作者提出的 **state-space expansion**（预置"槽位"被启用而扩张）被原文判为**语法内的操作** —— "扩展的可能性空间本身是先验给定的"。⟹ 这正是"真扩展 vs 语法内扩展"的原文版区分；本稿 §三 的"伪通过"一栏，就是它的操作化。

## 三、判定口径：每条"真通过"长什么样、"伪通过"长什么样

判据最容易坏在**伪通过**上，故每条都给"反例形态"：

| # | 真通过 | 伪通过（须判否） |
| :-: | :-- | :-- |
| 1 维度 | 新增**独立自由度**（新状态，旧状态表达不出） | 把已有参数塞进状态向量（记号搬家）；**装配式加维** |
| 2 拓扑 | 定性结构改变（连通性／紧致性／同胚类型） | 只做**同胚**（连续可逆）变形 |
| 3 范畴 | **换层**：对象与态射的含义变了（如加**内语言**） | 同范畴内换记号／换图表 |
| 4 类型 | **提升类型层级／universe**，或新增类型构造子 | 同层内加新记号 |
| 5 动力学 | 吸引子结构／分岔模式／稳定性景观的**定性**改变 | 只调参数、不改质性（**奖励层势整形**！）；**槽位激活**（语法内） |

> ★ 判据的用法全在这张表：**不亮**要排除"伪通过"，**亮**才认。

## 四、落到本项目那句问话：五条逐问

> **绑定（v1.2）**：本问绑定**系统内部状态空间**（原文四类状态空间之一）。

问：**「内稳态进入动力学」是否达到「状态空间扩展」？**

| # | 问 | 若只做**奖励层势整形**的判定 | 亮灯条件（怎么才算） |
| :-: | :-- | :-- | :-- |
| 1 | 维度变了吗？ | ✗ 状态向量维数不变 | 把**设定点**从参数提升为**状态**（新自由度） |
| 2 | 拓扑变了吗？ | ✗ 流形结构不变 | 让**边界／流形拓扑可变**（Markov 毯边界可重组） |
| 3 | 范畴换了吗？ | ✗ 仍停在 $`\mathbf{Set}`$ 上的动力系统 | 换到**生成状态空间的范畴**（拓扑斯／层论） |
| 4 | 类型层级扩了吗？ | ✗ 语言层级不变 | 提升**内语言／类型层级**（HoTT 的 universe） |
| 5 | 动力学标准变了吗？ | ✗ **奖励层势整形不改流** ⟹ 动力学未变 | **质性改变**：不动点 → **极限环**／分岔（**把 Φ 写进流**） |

★ 第五条这一栏，**判据要分两层**（**v1.2 的关键修订**）：

> **势整形定理**（Ng, Harada, Russell 1999 ＋ 本项目算例）：$`\gamma=1`$ 势整形 $`\tilde F=F+\gamma\,\Phi`$，其**最优策略不变**。其准确层是**奖励／策略层** —— 它**不动状态转移（流）**。
> **P1（奖励层）**：只改目标、不改流 ⟹ 流未变 ⟹ **五条全不亮**（判定成立，但**近乎恒真**）。
> **P2（景观层）**：把 Φ **写进流**（$`\dot x=-\nabla(F+\Phi)`$）⟹ **动力学质性可变**（`scripts/five_criteria/verify_shaping_vs_five_criteria.py` B：不动点移动；$`c>c_*`$ 鞍结分岔 3 → 1）⟹ 第五条**可亮**。
> ⟹ **"进入动力学" ⟺ "把 Φ 写进流"** —— 这才是第五条的门槛。

⟹ **判定**：若"内稳态进入动力学"仅停留在**奖励层势整形**，则**五条全不亮** ⟹ 判为**停在给定空间内变形** ⟹ 这就是**公理 II 缺口**（读解稿 §3.1 已述；此处给出**逐条形式化**）。

**而"落地"长什么样**：至少要**点亮一条** —— 最经济的入口是**第五条**：让动力学从"收敛到不动点"变成"**收敛到极限环**"。

> ★ 这正是"**内感受 × 五行**"比单内感受**多做的那一步**：加入相位项 $`i\omega z`$ 后，不动点变成**极限环**（$`\lvert z\rvert\to r_*`$ 钉、$`\arg`$ 自由）——**动力学定性变了**，第五条**亮**。

## 六、纪律与边界（必读）

1. **五条是"形式判据"，不是"本体论证明"**：命中五条 $`\nRightarrow`$ 本体论成立。原文 §7.4 自己就做了三档分（严格只有 Curry–Howard 那一行）—— 与本项目 `math-doc-rigor` 同一种纪律。
2. **五条判的是"空间是否生成"，不是"机制是否为真"**。"机制为真"（$`F`$ 是单一泛函、公理 II 成立）仍是**项目未证的那一格**。
3. **不得**把"本文划的线"与"项目公理 II"写成**同一件事**（承读解稿 §3.3 的纪律）；本稿只主张**同一条线的两种叫法**（空间生成 ／ 内生性）。
4. **（v1.2）**"状态空间扩展"是原文**八层谱系里的一格**；五条标准是**并列视角**（原文原话），本稿**不再**主张层级。
5. **（v1.2）** Friston 的"状态空间扩展（槽位激活）"被原文判为**语法内**，是"伪通过"的原文判例。
6. **（v1.2）** 势整形定理的**准确层是奖励／策略层**，**不是**动力学层；把它当第五条的判据属**层次错位**。
7. **（v1.2）**"内感受 × 五行"的**维度是"装配式"加的**（1 → 2 维），按原文口径**不算**"空间自己生成"；故 §五 标 **？**。
8. **（v1.3／v1.4）** 五实例逐格核的结论：**五条无一为 ✓**；四实例的"亮"都只落在"给定载体上的现象"（含 v1.4 补的涡旋绕数、八度圆），**缺口在"生成"**。§五 全表为**结构性判读**（非定理）。
9. 五条**归功原文**；本稿只做"落地化"，**不新增任何定理**。
