# 奇维 γ_ren 的"显式等式"：一次严格的否证

**——把 Part 二从"结构性"抬到严格：结果是 γ_ren ≠ c·η(0)**

---

## 〇、结论

上一份文档把"奇维 γ_ren 的载体 = η"标为**结构性**，并立为待办：算出显式等式 γ_ren = c·η(0)+⋯ 以升级为严格。

**执行的结果是：该等式不成立。** 严格结论：

> **γ_ren 与 η(0) 采样的是谱密度的两个正交扇区（偶 / 奇），二者互相独立，不存在 γ_ren = c·η(0)+⋯ 这样的（线性）关系。**

这正是对"把结构性误当等价"的一次拦截（三层关系原则）。下面给出**一般命题 + 显式反例**。

---

## 一、预想等式的来源

上一份的直觉是：γ = ζ_{|D|}(−1) 与 η(0) 都是"ζ/η 型解析延拓的有限部分"，故"应当"有 γ_ren = c·η(0)。

**这个"应当"是错的**——类型相同，**向量不同**。

---

## 二、一般命题：偶 / 奇扇区正交（严格）

设 D 自伴，谱 {λ_i}，谱密度 ρ(λ)。分解为偶部与奇部：

$$\rho_{\text{sym}}(\lambda)=\frac{\rho(\lambda)+\rho(-\lambda)}{2},\qquad \rho_{\text{asym}}(\lambda)=\frac{\rho(\lambda)-\rho(-\lambda)}{2}$$

两个母函数各只看一个扇区：

$$\zeta_{|D|}(s)=\sum_i|\lambda_i|^{-s}=\int|\lambda|^{-s}\,\rho_{\text{sym}}(\lambda)\,d\lambda$$

$$\eta(s)=\sum_i\mathrm{sgn}(\lambda_i)\,|\lambda_i|^{-s}=\int\mathrm{sgn}(\lambda)\,|\lambda|^{-s}\,\rho_{\text{asym}}(\lambda)\,d\lambda$$

原因很简单：|λ|^{-s} 为偶 ⟹ 只与 ρ_sym 相配；sgn(λ)|λ|^{-s} 为奇 ⟹ 只与 ρ_asym 相配（奇 × 偶 = 奇，积分归零）。

**推论。** γ_ren = Reg ζ_{|D|}(−1) 只依赖 ρ_sym；η(0) 只依赖 ρ_asym。而 ρ_sym、ρ_asym 可**独立变动** ⟹ **γ_ren 与 η(0) 独立**。∎

---

## 三、显式反例（d=1，严格）

取 S¹（周长 2π）上的自伴算子

$$D=-i\frac{d}{dx}+a,\qquad 0<a<1$$

本征函数 e^{inx}，本征值 λ_n = n+a（n∈ℤ）。

**γ 侧（偶）**：

$$\zeta_{|D|}(s)=\sum_{n\in\mathbb{Z}}|n+a|^{-s}=\zeta_H(s,a)+\zeta_H(s,1-a)$$

**η 侧（奇）**：

$$\eta(s)=\sum_{n\in\mathbb{Z}}\mathrm{sgn}(n+a)\,|n+a|^{-s}=\zeta_H(s,a)-\zeta_H(s,1-a)$$

用 Hurwitz ζ 的 Bernoulli 值 ζ_H(−1,q)=−B₂(q)/2、ζ_H(0,q)=1/2−q，得

$$\gamma_{\text{ren}}=\zeta_{|D|}(-1)=-a^{2}+a-\frac{1}{6}$$

$$\eta(0)=1-2a$$

**检验**：γ_ren 是 a 的**二次**函数，η(0) 是**一次**函数。故**不存在** c, c′ 使 γ_ren = c·η(0)+c′。∎

（顺带：本例只有单个参数 a，γ_ren 恰好可写成 η(0) 的**二次**式 γ_ren = 1/12 − η(0)²/4——但这只是"单参数"的巧合；多参数的一般谱里二者**完全独立**。这条二次巧合本身也足以排除任何**线性**关系。）

## 四、结论与修正

- **否证**：线性等式 γ_ren = c·η(0)+⋯ **不成立**。
- **修正**：上一份文档 Part 二 的"γ_ren 载体 = η"由"结构性"降级为**已排除**；正确表述是"**两个正交扇区的解析延拓有限部分**"。
- **不转移**：η(0) 的几何身份（APS 边界修正 / 3D Chern–Simons）**不能**自动赋予 γ_ren。
- **方法论**：这是"三层关系原则"的一次应用——**类型相仿（都是 FP）≠ 相等**。

于是"η 只在奇维非平凡"与"χ 只在偶维非零"形成**互补的对仗**——但这是**两个扇区各自的**平凡化，**不是** γ_ren 与 η 的等式。
