# 公理 III · 第三角：拓扑面（派生面）

**——用"精度结构诱导的拓扑"补齐第三角**

> **定位**：`notes/` 级 · **公理 III 的派生拓扑面**；配套提法一 / 二 / 三。

> **版本**：v1.0　**时间**：2026-09-27

## 0. 一句话

**拓扑面 = 精度结构诱导的"一致结构之拓扑不变量"（上同调）。** 它与几何面的边由 **$`H^1`$ 障碍（de Rham）** 闭合——这正是「公理II续2」"圆上耗散化的障碍"的一般化。**但它从信息面派生，不是独立提法。**

## 1. 形式化（从精度结构导出拓扑）

给定精度结构 $`\{\Pi_\epsilon\}`$（提法三）。令

$$U_\epsilon=\{(x,y)\in X^2:\ \Pi_\epsilon(x)=\Pi_\epsilon(y)\}.$$

$`\{U_\epsilon\}_\epsilon`$ 是**嵌套的等价关系族**（$`\epsilon_1<\epsilon_2\Rightarrow U_{\epsilon_1}\subseteq U_{\epsilon_2}`$）⟹ 构成 $`X`$ 的**一致结构基**（uniformity basis）⟹ 诱导**拓扑 $`\tau`$**。公理三的"极限重建" $`X\cong\varprojlim X_\epsilon`$ 即：

> **$`X`$ 的拓扑 = 精度系统的（pro-）极限拓扑。**

**拓扑面 $`=(\tau,\ H^*(\tau))`$**：精度结构诱导的拓扑及其上同调。

## 2. 边一：信息 → 拓扑（✓ 闭合 · 定义性）

$`\{\Pi_\epsilon\}`$（信息）⟹ 一致结构 ⟹ 拓扑 $`\tau`$ ⟹ 上同调 $`H^*`$（拓扑）。**这是标准构造（uniform space），闭合。**

**实例（可算）**：p 进 $`U_n=\{x\equiv y\bmod p^n\}`$ 嵌套、直径 $`p^{-n}\to0`$ ⟹ p 进拓扑 $`=`$ $`\mathbb Z_p=\varprojlim\mathbb Z/p^n`$ 的极限拓扑。

## 3. 边二：拓扑 ↔ 几何（✓ 闭合 · de Rham）★

**核心**：$`H^1`$ 是"**局部势能否整体化**"的障碍。

$$X^\flat\ \text{exact}\iff\big(X^\flat\ \text{closed}\ \wedge\ H^1=0\big).$$

（即：向量场（流）$`X`$ 是梯度 $`\iff`$ 对偶 1-形式 $`X^\flat`$ 恰当 $`\iff`$ 闭且 $`H^1=0`$。）

⟹ **$`H^1(X)=0`$ ⟹ 势（Hessian 的来源）可整体定义（几何面整体有效）；$`H^1\ne0`$ ⟹ 存在无势"纯旋转"，几何面须拓扑修正。**

**实例（可算）**：

| 空间 | 检验 | 结论 |
| :-- | :-- | :-- |
| 圆 $`S^1`$ | $`\oint d\theta=2\pi\ne0`$ | $`H^1(S^1)=\mathbb R\ne0`$ ⟹ 纯旋转无势（须补维） |
| 线 $`\mathbb R`$ | $`\int_1^4 h=F(4)-F(1)`$ | 单值势 ⟹ $`H^1(\mathbb R)=0`$（无洞） |

**这正是「公理II续2」的机制**：圆上耗散化的拓扑障碍 $`H^1(S^1)=\mathbb R`$ ⟹ 须补径向维度。**本角补齐的增量 = 把 bridge 的 $`H^1`$ 机制提升为公理 III 的一条正式边。**

## 4. 修正后的接通图

| 边 | 状态 | 依据 |
| :-- | :-- | :-- |
| 几何 ↔ 信息 | ✓ 闭合（定量） | $`\lambda_i=\epsilon_i^{-2}`$（Cramér–Rao） |
| 几何有限维 ↔ 连续极限 | ✓ 闭合 | 重整化（同一 $`\gamma`$） |
| 信息 → 拓扑 | ✓ 闭合（定义性） | 一致结构 / 极限拓扑 |
| 拓扑 ↔ 几何 | ✓ 闭合 | $`H^1`$ 障碍（de Rham） |
| 二（重整化）↔ 三（信息） | ✗ 仍未闭合 | 仅机制类比 |

⟹ **三角已闭（三条边各有依据）；"重整化 ↔ 信息"这条外接边仍只到机制类比。**

## 5. 诚实边界

- 拓扑面是**派生面**（从信息面构造），**不是第四提法**——故准确说法是"**两提法（几何面）× 两极限 + 信息面 + 派生拓扑面**"。**"三面"仍是误称**（面 $`=`$ 几何、信息；拓扑是从信息派生的不变量）。
- "信息→拓扑"是**标准构造**（非新定理）；"拓扑↔几何"是 **de Rham 经典事实**（非本项目新证）。故本角的"闭合"是**把既有标准事实装配进来**；增量在于**把 bridge 的 $`H^1`$ 机制提升为公理 III 的正式边**。
- **未闭合残余**：二（重整化）↔ 三（信息）——仅机制类比。

## 附：一句话

**第三角（拓扑面）可补齐，但派生自信息面：精度结构 ⟹ 一致结构 ⟹ 拓扑/上同调（信息→拓扑，定义性）；$`H^1`$ 障碍使"势能否整体化"成为拓扑↔几何的边（de Rham）。三角由此闭合，并把「公理II续2」的 $`H^1`$ 机制提升为公理 III 的正式边；唯"重整化↔信息"仍只到机制类比。**
