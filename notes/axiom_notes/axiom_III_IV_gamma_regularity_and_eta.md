# Part 一｜待办②：公理 III 推论——总曲率的正则性判据

## 一.1 陈述

**推论（总曲率正则性判据）。** 设公理 III 的 Hessian 之二阶化为 P = D²，热核系数为 a_k。则总曲率的规范重整化值 γ_ren 有限，当且仅当

$$a_{d+1}=0$$

等价说法：γ 无 log 发散 ⟺ a_{d+1}=0 ⟺ γ_ren = ζ_P(−1/2) 有限。

- **自动满足**：无边界 + d 偶 ⟹ a_{d+1}=0 ⟹ γ_ren 有限。
- **失效（须重整化）**：d 奇，或带边界。

## 一.2 证明（三步）

**第一步：极点判据。** ζ_P 的极点在 s=(d−k)/2；s=−1/2 ⟺ k=d+1。故 s=−1/2 是极点 ⟺ a_{d+1}≠0。

**第二步：极点 = log 发散。** γ 的 Mellin 变换为

$$\Gamma(s)\,\zeta_P\!\left(s-\frac{1}{2}\right)=\int_0^\infty \gamma(t)\,t^{s-1}\,dt$$

在 s=0 处，Γ(s) 与 ζ_P(−1/2) 各有一个**单极点**，乘积是**双极点**；双极点对应 γ(t) 含 **log t**。故 s=−1/2 是极点 ⟺ γ 有 log 发散。

**第三步：减 log 取有限。** log 可减除（§4.4 范式），减后即得 γ_ren。

## 一.3 与推论 1（Heisenberg）并列

| 推论 | 内容 | 类型 |
| :-- | :-- | :-- |
| 推论 1（Heisenberg） | Δψ²·γ ≥ n² | **下界** |
| 推论 2（本页） | γ_ren 有限 ⟺ a_{d+1}=0 | **可重整化** |

两条合起来给出总曲率的性情：**γ 有下界，且在 a_{d+1}=0 时可规范重整化为有限量。**

## 一.4 意义

判据是**可计算的**：给定泛函的二阶变分（即 P），只需看 a_{d+1} 是否为零，即可判定"总曲率是否发散"。这给公理 III 的 γ 补上了一条**结构可控性**。

# Part 二｜待办①：奇维 γ_ren 的 η 载体

## 二.1 奇维 ⟹ log 发散

d 奇 ⟹ a_{d+1}≠0 ⟹ γ 含 **log 发散**（Part 一.2）。这正是 §4 的 W 里 πlogη·Σχ(p) 的**同一类型**——**log 型、可减除**。

## 二.2 有限部分

$$\gamma_{\text{ren}}=\mathrm{FP}_{s\to-1/2}\ \zeta_P(s)$$

即"减 log（极点）取有限"。问题只剩：**这个有限部分是什么？**

## 二.3 同类对象：η 不变量

定义 η 函数

$$\eta(s)=\sum_{\lambda\neq0}\mathrm{sgn}(\lambda)\,|\lambda|^{-s}$$

其解析延拓值 η(0) **本义就是"减极点的有限部分"**——与 γ_ren **同类型**（ζ/η 型解析延拓的有限部分）。

两者是"姊妹"——一个数总谱，一个数谱不对称：

$$\zeta_{|D|}(s)=\sum|\lambda|^{-s},\qquad \eta(s)=\sum\mathrm{sgn}(\lambda)\,|\lambda|^{-s}$$

其中 γ = ζ_{|D|}(−1) 是"总曲率"，而 η(0) 是"**不对称**的有限部分"。

## 二.4 几何身份：APS 与 Chern–Simons

η(0) 有明确的几何身份：

- **APS 指标定理**（Atiyah–Patodi–Singer）：边界修正正是

$$\mathrm{Ind}_{\text{APS}}=\int_{\text{bulk}}(\cdots)-\frac{1}{2}\big(\eta(0)+h\big)$$

其中 h 为零模数。η(0) 是**边界贡献**。

- **3 维 Chern–Simons**：CS 项是 3 维流形上的拓扑项，其"层级"与 η 同源（在 APS 框架下，CS 的变分给出 η）。

于是：奇维 γ_ren 与 η 不变量**同型**（都属于"ζ/η 型解析延拓的有限部分"）。

> ⚠️ **修正（v1.1）**：该"同型"**不能升格为等式**。经严格检验（见 `gamma_ren_explicit_refutation.md`），γ_ren 与 η(0) 采样的是谱密度的**正交扇区**（偶 / 奇），二者**独立**，**不存在** γ_ren = c·η(0)+⋯。故下文的"载体"只能读作"**同型类比**"，不是"相等"；η(0) 的 APS/CS 身份**不转移**给 γ_ren。

## 二.5 三者并列

| 情形 | 发散型 | 有限部分（同型归属） |
| :-- | :-- | :-- |
| **d 偶 + 无边界** | 无（仅幂） | ζ_P(−1/2)（纯有限修正） |
| **d 奇** | **log** | 与 η 同型（**但独立**，见修正） |
| **带边界** | **log** | 与 η 同型（**但独立**，见修正） |

**统一**：**log 发散 ⟹ 有限部分与 η 同型**（同型 ≠ 相等，见二.4 修正）；而无 log（d 偶无边界）⟹ 有限部分是"干净"的 ζ_P(−1/2)。这与 §4 的 W（log ⟹ W）是**同一机制**。

## 小结

- **Part 一**：公理 III 补上**正则性判据**——γ_ren 有限 ⟺ a_{d+1}=0；与 Heisenberg 推论并列（下界 + 可重整化）。
- **Part 二**：奇维 γ 的**发散是 log 型**；有限部分与 η **同型**（但**独立**，见修正）。
- **统一图景**：**log 发散 ⟹ 有限部分与 η 同型**；无 log ⟹ 干净的 ζ_P(−1/2)。与公理 IV 的 W 同机制。
