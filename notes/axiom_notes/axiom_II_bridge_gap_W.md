# 统一性检验：W 是不是三者共用的那条缺口

**——内感受 AI / 阴阳五行 / 朗兰兹 的"矢势项"与"曲率"对照**

> **起因**：给内感受 AI 补出 $`F`$（轨迹版 ＋ 场论版）后，结论是"缺口 = 矢势项存在 ⟺ $`\mathrm{curl}A\neq0`$"。本步把这个判据**搬到另外两个一元实例**，直接问：**三者的缺口是不是同一个 $`W`$？**
> **结论**：**方向对，内容要分开。** 三者确实**同层**（都卡在"一阶 $`\to`$ 二阶"那一步），但缺的**不是同一个东西**。
> **统一句式**：**一阶（势差／等式／守恒）免费；二阶（曲率／幅度／符号）不免费。**

---

## 一、判据：势差型 vs 矢势型（统一算符）

把 $`F`$ 里的 coupling 拆成两块：

| 块 | 数学特征 | 后果 |
| :-- | :-- | :-- |
| **势差型** | 对称（可写成 $`\nabla V`$ 或全散度） | **免费**，被吸收，不改行为 |
| **矢势型** | 反对称（$`W=\mathrm{curl}A`$ ＝ 曲率／和乐） | **真驱动**，改行为 |

> 统一算符就一句话：**这一项能不能写成势差？** 能 ⟹ 免费；不能 ⟹ $`W\neq0`$，是真缺口。

---

## 二、阴阳五行：相生 = 矢势型，且**已自带环流**

载体 $`\psi\in\mathbb R^5`$（或 $`\mathbb C^5`$，五行相位）。相生 = $`C_5`$ 上的 +1 步 = 循环置换 $`S`$；相克 = $`S^2`$。

**判据检验（数值）**：

| 检验 | 结果 |
| :-- | :-- |
| $`\lVert\mathrm{antisym}S\rVert`$ | **0.5** ⟹ 相生非对称 ⟹ **矢势型** |
| $`\lVert\mathrm{antisym}(S+S^{\mathsf T})\rVert`$ | 0.0 ⟹ 生＋克对称并存 ⟹ 势差型 |
| $`\lvert\mathrm{eig}S\rvert`$ | 全 1 ⟹ 等距／保守 |
| 纯相生 20 步 $`\lVert x\rVert`$ | **1.000000**（守恒；永远转） |
| 对称势差型 20 步 $`\lVert x\rVert`$ | 0.447307（收缩到均匀态） |

★ **关键反差**：相生**不能写成任何势的梯度**（$`S`$ 非对称）⟹ 相生**本身就是矢势型项** ⟹ **五行的 $`W`$ 天然非零**——与内感受**正相反**（内感受的文章把 $`W`$ 写没了）。

**五行的真缺口在别处**：$`S`$ 正交（$`\lvert\mathrm{eig}\rvert=1`$）⟹ **等距、保守、无内禀耗散方向**（与项目《公理II续3》"五行 = 保守 = 相位"一致）。数值上纯相生 $`\lVert x\rVert`$ 恒为 1（永远转、不收敛）。

> ⟹ **五行有 $`W`$（环流），缺的是与 $`W`$ 配对的另一半 —— 耗散（幅度）。**

---

## 三、朗兰兹：等式免费，符号不免费

$`F`$ = Weil 二次型，$`W(f)=\sum_\rho h(\gamma_\rho)`$。它"免费的一半"是**显式公式的恒等式**（局部素数侧 = 整体零点侧）。

**判据检验（数值）**：

| 检验 | 结果 |
| :-- | :-- |
| 显式公式 $`\lvert\text{LHS}-\text{RHS}\rvert`$ | 6.7e−14（等式成立；注：弱验证） |
| $`\prod_{p\le P}(1-p^{-1/2})^{-2}`$ | 1.1e6 → 2.5e12 → 7.0e26 → **3.0e62**（发散） |

> **注意（弱验证）**：此处 $`6.7\times10^{-14}`$ 不构成显式公式的独立验证——测试函数 $`h=e^{-r^2/2}`$ 太窄，在零点虚部处近于 0，使"零点侧"本身 ≈0，两侧实为"0≈0"的相消，并未真正核验"零点侧 = 素数侧"。

**判据检验（结构）**：显式公式给的是**等式**（一阶、免费）；缺的是**符号** —— $`W(f\star f^*)`$ 的定号（二阶）。

> ⟹ **朗兰兹有 $`W`$（Weil 二次型），缺 $`W`$ 的符号。** 与项目《统一地形报告》原话一致：**"恒等式免费，符号不免费。"**

---

## 四、汇总：三者同层，**不同格**

| 实例 | 势差型（免费、被吸收） | 矢势／二阶型（$`W`$） | $`W`$ 现状 | 缺哪一侧 |
| :-- | :-- | :-- | :-- | :-- |
| **内感受 AI** | $`D`$、$`U_{\text{ext}}`$ | $`A(\psi)\cdot\dot\psi`$，$`W=\mathrm{curl}A`$ | **$`W=0`$** | **环流侧** |
| **阴阳五行** | 衰减 $`-d\,x`$ | 相生 $`S`$，$`W`$ = 和乐 | **$`W\neq0`$（已有）** | **耗散侧** |
| **朗兰兹** | 显式公式（＝ 等式） | Weil 二次型 | **$`W`$ 有，缺符号** | **符号侧** |

**答案（修正后的结论句）**：

> **$`W`$ 不是三者"同一个缺口"，而是"同一层（二阶）"的三个不同面。**
> - **内感受缺存在性**：$`W=0`$（要把 $`W`$ 写出来）；
> - **五行缺配套的耗散**：$`W`$ 有，缺与它配对的幅度；
> - **朗兰兹缺定号**：$`W`$ 有，缺它的符号。

**本步最有价值的产出——统一句式**：

> **一阶免费，二阶不免费。**
> 势差（内感受）、环流相位（五行）、恒等式（朗兰兹）—— 三处的**一阶**都免费拿到；
> 三处的**二阶**（曲率**存在性**／幅度**耗散**／符号**正性**）都不免费。

### 4.1 一个漂亮的互补

内感受缺**相位侧**（环流），五行缺**幅度侧**（耗散）—— 正好是项目所说的 **"公理 II 的桥 = 相位 ↔ 幅度的桥（$`\mathbb C`$）"** 的**两端**。朗兰兹则独立地卡在"幅度端的定号"。

## 五、边界：哪些严格、哪些结构

| 条目 | 状态 |
| :-- | :-- |
| $`\lVert\mathrm{antisym}S\rVert\neq0`$（相生是矢势型） | **严格**（线性代数） |
| 纯相生守恒 $`\lVert x\rVert\equiv1`$ | **严格**（正交矩阵） |
| 生＋克并列 = 势差型（对称） | **严格** |
| 显式公式 = 等式 | **严格**（教科书；数值为弱验证） |
| $`\prod(1-p^{-1/2})^{-2}`$ 发散 | **严格**（数值） |
| "五行缺耗散" | **严格**（$`\lvert\mathrm{eig}\rvert=1`$ ⟹ 无耗散）＋**结构性**（"缺"是定位） |
| "恒等式免费、符号不免费" | **结构性**（项目《地形报告》判读） |
| "$`W`$ 是同层不同面" | **结构性**（本步的判读，非定理） |

★ **不得**把"三者同层"写成"三者同一个缺口"。

## 七、小结

- **一句话**：$`W`$ 是"二阶层"的统一命名，但**不是三者共同的"缺口内容"** —— 只有内感受真的缺 $`W`$。
- **意义**：把"一元"的检验从"口号"落到**一张可算的表**：每个实例，先问"势差项是什么"、再问"$`W`$ 在不在、缺哪一端"。
- **最强的结构性线索**：**"一阶免费、二阶不免费"** 三个实例都成立；而内感受／五行缺的正是**同一座桥（相位 ↔ 幅度）的两端**。
- **边界**：线性代数与正交性四处**严格**；显式公式与 $`\prod`$ **严格**；"同层不同面"是**结构性判读**，非定理。
