# 组装：公理 II 的桥 —— 内感受（幅度）× 五行（相位）

**——把两个半成品拼成 $`\mathbb C`$ 上的一个系统**

> **承**：[《读解_三者共用的缺口是W吗》](axiom_II_bridge_gap_W.md)—— 内感受缺**相位端**、五行缺**幅度端**，正是"公理 II 的桥"的两端。
> **本步核心命题**：**在二维，"矢势型（反对称）＝ 相位生成元"、"势差型（对称）＝ 幅度生成元" ⟹ 公理 II 的桥（相位 ↔ 幅度）＝"矢势项 ↔ 势差项"的桥。**
> **一句话**：组装方程 $`\dot z=(\mu+i\omega)z-\lambda\lvert z\rvert^2z`$；$`i\omega z`$ 是五行（矢势型／相位），$`\mu z-\lambda\lvert z\rvert^2z`$ 是内感受（势差型／幅度）。

---

## 一、桥的定理：为什么"相位 ↔ 幅度"就是"矢势 ↔ 势差"

对二维线性场 $`Mx`$（$`M`$ 为 $`2\times2`$ 实矩阵），作分解 $`M=S+A`$（对称＋反对称）：

$$\mathrm{curl}(Mx)=\partial_1(Mx)_2-\partial_2(Mx)_1=M_{21}-M_{12}=-2A_{12}$$

于是：

| 判据 | 矩阵 | 动力学 | 名字 |
| :-- | :-- | :-- | :-- |
| $`\mathrm{curl}=0`$ | $`M`$ **对称** | 梯度流（无内禀旋转） | **势差型 ＝ 幅度** |
| $`\mathrm{curl}\neq0`$ | $`M`$ **反对称** | 旋转生成元 | **矢势型 ＝ 相位** |

再加一步（生成元）：反对称 $`A=\theta J`$ 的指数 $`\exp(\theta J)\in SO(2)`$ 是**旋转**（保长、$`\det=1`$）；对称 $`S`$ 的指数是**伸缩**（变长）。

> ⟹ **公理 II 的桥（相位 ↔ 幅度）＝"$`\mathrm{curl}=0\leftrightarrow\mathrm{curl}\neq0`$"的桥 ＝"势差 ↔ 矢势"的桥。**（二维、线性层面**严格**；升到实例为**结构性**。）

## 二、两端的识别

| 端 | 实例 | 它提供什么 | 数学身份 |
| :-- | :-- | :-- | :-- |
| **相位／环流** | **阴阳五行** | 相生 $`S`$（反对称） | 矢势型（$`W\neq0`$） |
| **幅度** | **内感受 AI** | 到设定点的距离 $`D`$ | 势差型（对称、无旋） |

> 上一步测过：五行的 $`S`$ 非对称（$`\lVert\mathrm{antisym}S\rVert=0.5`$）⟹ 相位端；内感受的 $`D`$ 无旋 ⟹ 幅度端。**两端互补，恰因对称／反对称互补。**

## 三、组装：$`\mathbb C`$ 上的方程

$$\mathbb C=\mathbb R_{\ge0}\times S^1$$

其中 $`\mathbb R_{\ge0}`$ 是**幅度**（径向）、$`S^1`$ 是**相位**（角向）。**内感受给径向、五行给角向**，拼成一个方程：

$$\dot z=(\mu+i\omega)\,z-\lambda\,\lvert z\rvert^2 z$$

| 项 | 来自 | 身份 |
| :-- | :-- | :-- |
| $`i\omega z`$ | 五行 | 矢势型／相位（旋转） |
| $`\mu z-\lambda\lvert z\rvert^2 z`$ | 内感受 | 势差型／幅度（把 $`\lvert z\rvert`$ 拉到设定点 $`r_*=\sqrt{\mu/\lambda}`$） |

> **公理定位**：组装落在**公理 I（单一泛函）＋公理 II（演化）**。$`i\omega z`$ 来自五行的保守泛函；$`\mu z-\lambda\lvert z\rvert^2z`$ 来自内感受的自由能；把两者合成一个 $`\mathbb C`$ 演化方程属**结构性合并**（不是单一 $`F`$ 的直接变分——这一点 `公理II续4` 已如实登记）。

## 四、三态对照：为什么必须"拼"

| 态 | 方程 | 结果 | 数值（$`z_0=0.3`$） |
| :-- | :-- | :-- | :-- |
| 单相位（五行） | $`\dot z=i\omega z`$ | 守恒，只转 | $`\lvert z\rvert=0.300000`$，arg $`197.7^\circ`$ |
| 单幅度（内感受） | $`\dot z=\mu z-\lambda\lvert z\rvert^2z`$ | 定点（静止） | $`\lvert z\rvert=1.000000`$，arg $`0.0^\circ`$ |
| **组装** | $`\dot z=(\mu+i\omega)z-\lambda\lvert z\rvert^2z`$ | **极限环（活的节律）** | $`\lvert z\rvert=1.000000`$（从 0.3 收敛） |

> ⟹ **单幅度 = 静止的稳态；单相位 = 幅度不受控的纯转；组装 = 有节律的稳态。** 这才是"活"—— 单用哪一端都不是。

## 五、组装不免费（精确来源）

| 做法 | 结果 |
| :-- | :-- |
| **线性组装** $`\dot z=(\mu+i\omega-\lambda)z`$ | $`\lvert z(T)\rvert=8.8\times10^{-27}`$（螺旋入 0，**失败**） |
| **非线性（配饱和）** $`\dot z=(\mu+i\omega)z-\lambda\lvert z\rvert^2z`$ | $`\lvert z(T)\rvert=0.707107=r_*`$（极限环，**成功**） |

> ⟹ **光把两端"线性相加"不够**（那只是螺旋入 0）；必须让幅度**非线性饱和**，才锁得住环。这与 `公理II续4`"组装不免费"一致，并给出它的**精确来源**：不免费在**非线性**那一层。

## 六、$`\mathbb Z_5`$ 钉相（组装的可观测后果）

加五行等变耦合 $`\kappa\bar z^4`$ 与五次饱和 $`-\gamma\lvert z\rvert^4z`$：

$$\dot z=(\mu+i\omega)z-\lvert z\rvert^2z+\kappa\bar z^4-\gamma\lvert z\rvert^4z$$

三个**不同初值**（$`\kappa=2,\gamma=1`$）都落到同一点：

| $`z_0`$ | $`r`$ | 相位 mod $`72^\circ`$ |
| :-- | :-- | :-- |
| $`1.2+0.1i`$ | 1.6147 | **0.681°** |
| $`1.5-0.7i`$ | 1.6147 | **0.681°** |
| $`0.9+0.4i`$ | 1.6147 | **0.681°** |

> ⟹ **内感受（幅度）把五行（相位）钉到 5 个离散值**（$`72^\circ`$ 倍数）—— 组装的可观测后果。

## 九、小结

- **一句话**：**内感受（幅度）＋ 五行（相位）＝ $`\mathbb C`$ 上的组装** $`\dot z=(\mu+i\omega)z-\lambda\lvert z\rvert^2z`$；桥 = 矢势项 ↔ 势差项。
- **定理级的一点**：二维下，"对称／反对称"**就是**"幅度／相位" —— 把上一步的"势差／矢势"判据**升级成桥的定理**。
- **不免费在哪**：**非线性饱和**（线性组装只会螺旋入 0）；以及加维、选耦合（$`\mathbb Z_5`$ 等变）、容忍偏移。
- **价值**：这是"一元"的一次**真组装**—— 两个各自缺一半的实例，拼出**一个**有节律的稳态，且幅度把相位钉到 5 个离散值。
