## 2. 欧拉类真的是「②层缺口的样子」吗？（读解②·自查订正）

### 2.1 结论先行（三句）

| # | 判定 |
| :-- | :-- |
| 1 | ✗ 「**整体上不存在**」说过头——毛球定理是**无条件非存在定理**；②层只是**构造缺席**（对存在与否不可知）。二者不是一回事。 |
| 2 | ✗ 「**欧拉类就是截面障碍**」也说过头——它只是**初级**障碍；一般秩下还有更高障碍（反例：$`S^4`$ 上秩 3 丛）。 |
| 3 | ✓✓ 真正立得住的是：欧拉类示范了「**用一个整体不变量作充要判据**」这一范式；而与 RH 的差别在【**方向相反**】——毛球定理用「量 $`\neq0`$」判**不存在**，RH 要用「定号」判**存在且位置固定**。 |

### 2.2 障碍理论：欧拉类只是「初级」一步

秩 $`n`$ 丛处处非零截面的障碍住在

$$ H^{k+1}\!\left(B;\ \pi_k(S^{n-1})\right),\qquad k=n-1,\,n,\,\dots $$

$`k=n-1`$ 那一步给 $`H^n(B;\mathbb Z)`$——即**欧拉类**。它能走几步，取决于 $`\pi_k(S^{n-1})`$ 是否非零。

| 情形 | $`H^3`$ 障碍 | $`H^4`$ 障碍 | 结论 |
| :-- | :-- | :-- | :-- |
| 秩 2 over $`S^2`$ | $`H^2(S^2;\pi_1(S^1)=\mathbb Z)=\mathbb Z`$（= e） | $`\pi_2(S^1)=0`$ | **e 是唯一障碍** |
| 秩 3 over $`S^4`$ | $`H^3(S^4)=0`$ ⟹ e 被迫为 0 | $`H^4(S^4;\pi_3(S^2)=\mathbb Z)=\mathbb Z`$（可非零） | **有 e 之外的更高障碍** |

**算据 B**：$`\pi_3(S^2)\neq0`$ 用 Hopf 不变量（= 两条纤维的环绕数）实算，$`\mathrm{Link}=1.0000`$ ⟹ $`\pi_3(S^2)\cong\mathbb Z`$ 真非零，故一般秩下确实有 e 管不到的障碍。

### 2.3 毛球定理 ≠ ②层缺口（关键区分）

| | **毛球定理** | **②层缺口** |
| :-- | :-- | :-- |
| 命题类型 | 无条件**非存在定理** | **构造缺席**（存在与否不可知） |
| 判据 | $`\int_{S^2}e=\chi(S^2)=2\neq0`$ | **？（没有）** |
| 结论 | **不存在** | **未知** |

> 说「整体上不存在」其实是把毛球定理的**结论**安到了②层的**状态**上。②层的真状态是「**我们还造不出来**」，**不是**「它不存在」。

### 2.4 正面收获：判据量 vs 量

欧拉类的范式是：**局部数据 → 一个可计算的【整体不变量】→【充要】判定一个整体存在性问题**。

| 我们**有** | 我们**缺** |
| :-- | :-- |
| 整体不变量很多：函数方程、Riemann–von Mangoldt、Weil 显式公式 | **一个能「判定」存在／位置的量** |

> ⟹ **②层缺的不是「没有量」，而是「没有一个能当判据的量」。** 原来的「不是算不出来而是不存在」混淆了「没有量」与「没有判据量」。

### 2.5 最锋利的一条：方向相反

| | 毛球定理 | RH 需要的 |
| :-- | :-- | :-- |
| 方向 | **反证式**：量 $`\neq0`$ ⟹ 不存在 | **构造式**：造出对象 ＋ 定号 ⟹ 全在线上 |
| 用的量 | 欧拉类（上同调类，整数值） | Weil 正性（二次形式的符号） |
| 判定什么 | 存在性 | 存在性 ＋ 位置 |

> 欧拉类之所以「一步到位」，恰恰因为它**不需要对象存在**——它证的是**不存在**。而②③层的顺序是：**②先要造出来，③才谈得上定号**。准确关系是：**同类家族、方向相反**（格式同型，不是同一件事——与 `09` 纪律一致）。

## 4. Wu–Yang 两补丁 = 转移函数吗？（读解③·订正）

> 算据 `verify_wuyang_patch.py`（A–E 五验，exit 0 全绿）。方法：先算后说 ＋ 内部一致性自检。

### 4.1 结论先行

| # | 判定 |
| :-- | :-- |
| 1 | ✓ 「两者差一个规范变换」对；但**差不是转移函数**——差是转移函数的**对数微分**（差是「速度」，转移函数是「位置」） |
| 2 | ◐ 「Möbius 的 $`\pm1`$ 是它最简单的非平凡实例」——**类别对，账本不同**：Möbius 记在 $`\mathbb Z_2`$（绕数 $`0`$、和乐 $`-1`$），单极记在 $`U(1)`$（绕数 = 荷） |
| 3 | ✗ 「与 `07` 的共格／不共格完全同一件事」说过头——应为**同型、不同账本** |

### 4.2 核验①：差是转移函数的对数微分

标准取法（Wu–Yang 1975，自然单位）：

$$ A_N=\frac{c}{2}(1-\cos\theta)\,d\varphi,\qquad A_S=-\frac{c}{2}(1+\cos\theta)\,d\varphi $$

**算据 A**：$`A_N-A_S=c\,d\varphi`$（与 $`\theta`$ 无关）✓，且两补丁给**同一曲率** $`F=(c/2)\sin\theta\,d\theta\wedge d\varphi`$ ✓。**算据 B**：两者绕数同为整数 $`c`$（$`c=1,2,-1,3`$）。故「差」是 $`\frac{1}{i}g^{-1}dg`$ 同型的量：**差是「速度」，转移函数是「位置」**。

### 4.3 核验②：$`\pm1`$ 是「最简单的实例」吗——是，但另一本账

| | **Möbius** | **单极（Wu–Yang）** |
| :-- | :-- | :-- |
| 转移函数取值 | $`\pm1`$（**局部常值**） | $`e^{ic\varphi}`$（**有绕数**） |
| 结构群 | $`\mathbb Z_2`$（离散） | $`U(1)`$（连续） |
| 记账的上同调 | $`H^1(\cdot;\mathbb Z_2)\cong\mathbb Z_2`$（$`w_1`$） | **绕数** $`\in\pi_1(U(1))\cong\mathbb Z`$（$`c_1`$，本质 $`H^1(S^1;\mathbb Z)`$） |
| 曲率 | $`0`$（平坦） | $`(c/2)\sin\theta\neq0`$ |

> **修正**：$`\pm1`$ 是**转移函数这个概念**最简单的非平凡实例，**不是** Wu–Yang 绕数型转移函数的实例——它的绕数是 $`0`$。**同为转移函数，两本账。**
> （**记法精修**：原写作 $`H^1(S^1;U(1))\cong\mathbb Z`$——非标准；绕数的诚实承载是 $`\pi_1(U(1))\cong\mathbb Z=H^1(S^1;\mathbb Z)`$，陈数本身更规范住在 $`H^2(S^2;\mathbb Z)\cong\mathbb Z`$。）

### 4.4 核验③：「完全同一件事」→「同型、不同账本」

`07` 的「共格」是 $`\{\log p\}`$ 能否共享同一个格（格距）；cocycle 条件是 $`g_{ij}g_{jk}=g_{ik}`$ 粘合能否结合。两者**形状相同**（都用同一套规则把各片接起来），**内容不同**。且原句「完全同一件事」与同篇「结构性对位、不是等价」**自相矛盾**，故改。

### 4.5 正面收获：两补丁之差**同时住着 `08` 的两级**

**算据 C**：取 $`\Lambda(\varphi)=c\varphi`$（$`c=1`$）——$`A_N-A_S=d\Lambda`$ 闭而不恰当（$`\Lambda(2\pi)-\Lambda(0)=2\pi c\neq0`$）：**ℝ-级有内容**；$`g_{NS}=e^{i\Lambda}`$ 单值须 $`c\in\mathbb Z`$：**ℤ-级更严**。**算据 D**：$`\int_{S^2}F=2\pi c`$ ⟹ 陈数 $`=c=`$ 绕数。

> **局部（差）可单值，整体（转移函数）须记账。** 这是那句老话的严格化身——原句只写「差 = 转移函数」，反而丢掉了这两级。

### 5.1 第 1 条：环绕数 = 1（算法先行）

夹具（已知 Hopf 链 $`|Link|=0.999979`$）先证方法可信；多对实算（对极 / 一般 / 近邻，$`M=400\to800`$ 收敛）；换投影中心 $`+0.999994\to-0.999990`$ 证**符号随定向翻转**。**连通性论证**（比抽查强）：有序不同点对空间连通 ＋ 环绕数连续整值 ⟹ 常数，不必逐对验。

### 5.2 第 2 条：四个名字——三个对、第五个错位

| 候选名字 | 数值（$`c=1,2,-1`$） | 判定 |
| :-- | :-- | :-- |
| 第一陈数 $`c_1=\frac{1}{2\pi}\oint_{S^2}F`$ | $`+1.0000,+2.0000,-1.0000`$ | ✓ $`=c`$ |

### 5.3 第 4 条：Berry 与狄拉克弦

**Berry 相位 = 和乐** ✓（要分两级）：ℝ-级回路相 $`\gamma=\frac{c}{2}\Omega`$（自旋-1/2 $`\gamma=-\Omega/2`$ 四角精确 ✓）；ℤ-级闭曲面 $`\frac{1}{2\pi}\int F=c_1`$。**关键对照**：绕满整球 $`e^{i\gamma}=1.000000`$ 看不见非平凡，而 $`c_1=-1\neq0`$ 记录得清清楚楚——**ℝ-级看不见的，ℤ-级看得见**。**狄拉克弦** ✓：局部奇点 = 转移函数欠下的账；「与读解②**同构**」应降为「**同型/呼应**」（无结构保持映射）。

### 5.4 ⚠ 系统性发现：三处同一条分界线

| 位置 | 一维（回路，ℝ-级） | 二维（闭曲面，ℤ-级） |
| :-- | :-- | :-- |
| 第 2 条 | 赤道和乐角 $`/2\pi=c/2`$ | 曲率积分 $`/2\pi=c_1=c`$ |
| 第 4 条 | Berry 相位 $`=\frac{c}{2}\Omega`$ | Berry 曲率积分 $`/2\pi=c_1`$ |
| 第 3 条 | 差 $`d\Lambda`$（1-形式） | 转移函数 $`e^{i\Lambda}`$（绕数） |

> 三处是**同一族病**：「位置/速度」「回路/闭曲面」「1-形式/群元素」都是**同一条 ℝ-级 ↔ ℤ-级 的分界**，而这条分界正是 `08` 的**两级结构**。⟹ §三 的毛病不是三处口误，是一处系统性偏差。

### 5.5 诚实记录：一次推理错误（cobound ≠ bound）

一度推：连接两基点的子午弧原像 = $`S^3`$ 里的环带，二边界正是两根纤维 ⟹ $`[C_1]+[C_2']=0`$ ⟹ $`\mathrm{Link}=0`$。**错在**：环带只给 $`[C_1]=-[C_2']`$，**推不出** $`[C_2']=0`$——**cobound（共同边界）$`\neq`$ bound（各自填满）**。而 $`[C_2']`$ 恰是**自链数**（环带诱导的 framing）= Hopf 不变量 $`=\pm1`$。正确结论反而是 $`\mathrm{Link}=\mp1`$（与数值一致）——**是数值纠正了解析**。

## 6. 整数化 · 度数版（08 补章）

> 承接 `06` 第三角边二（拓扑↔几何，$`H^1`$ 障碍）。脚本 `explore_gongli3_h1_integral.py`。结论：边二有**两级**——ℝ-级（周期，判「势是否存在」）与 ℤ-级（度数，判「障碍可否离散记账」）。

### 6.1 补一级：ℤ-级

$$ n=\frac{1}{2\pi}\oint_{S^1}\omega\ \in\mathbb Z $$

连接映射 $`H^1(S^1;\mathbb Z)\to H^1(S^1;\mathbb R)`$，像 = 格 $`\mathbb Z`$（在 $`\mathbb R`$ 里）。

| 级 | 群 | 障碍 | 判据 | 它在问什么 |
| :-- | :-- | :-- | :-- | :-- |
| 连续级 | $`H^1(S^1;\mathbb R)=\mathbb R`$ | 周期 $`\oint_{S^1}\omega`$ | $`\oint\omega=0`$？ | 势是否存在 |
| 整数级 | $`H^1(S^1;\mathbb Z)=\mathbb Z`$ | **度数** | $`n=`$ 能否定义？ | 障碍可否离散记账 |

（算据 B：$`\omega=\alpha\,d\theta`$，$`\alpha=0,1,1/2,\sqrt2`$ —— 整数化不是替换，是补出 ℝ-级下的一格。）

### 6.2 `n` 的双重身份在此合一

分析视角（`07`）$`n`$ = 分辨等级；拓扑视角（本篇）$`n`$ = 度数 $`=\deg(\lambda^{is}|_{C_\mu})`$。算据 A：数值绕数全准；ζ-cycle 取 $`n=2`$ 时 $`sL/2\pi=2.000000`$。⟹ 同一个 $`n`$，既是分辨等级，又是度数——**它同时坐在两条边上的同一格**。

### 6.3 新判据：可离散化 ⟺ 旋转数有理

圆上旋转 $`\dot\theta=\alpha`$，看轨道 $`n\alpha\bmod 1`$：$`\alpha=1,1/2,1/3`$（有理）→ 轨道**闭**（覆盖 1/2/3 格）；$`\alpha=\sqrt2`$（无理）→ **稠密**（覆盖 200 格）。

> **旋转数有理 ⟹ 轨道闭 ⟹ 可离散记账；无理 ⟹ 稠密 ⟹ 不可。**
> 而 ζ-cycle 要求更强的一档：**整数（不只是有理）**——对应「度数存在」，而非仅仅「有理旋转」。

（§5 与 `07` §S4(C) 互相印证：各 place 旋转数 = $`sL_p/2\pi`$，联合离散化须 $`\{L_p\}`$ 共格——两处独立得到同一条件。）
