## 摘要

朗兰兹纲领说：**自守侧与算术侧是同一个东西的两种读法**。

这正是"一元"的形态 —— **两本账**。本篇把它按四条公理落位，并如实回答一个问题：

> **它是"统一"，还是"统一的一个实例"？**

**结论**：是一个**实例**，而且是一个**已证到一半、缺口已精确定位**的实例。

- **一元形态**：朗兰兹对应 = 两本账（自守 / 算术）；其具体形式是**显式公式**与**Lefschetz 迹公式**；
- **函数域**（曲线）：两本账 ✓、正性 ✓（交形式 / Hodge 指标）、`F` ✓ —— **完整实例，已证**；
- **数域**：两本账 ✓（显式公式），**正性缺口** ✗ —— 十次修订后，缺口锁定为**一个格子**：`(Spec ℤ, 零点结构)`；
- ★ **公理 II 的特殊位置**：`δF = 0` 的"演化"在链上有名字 —— **Frobenius 流**，生成元 `Θ`；
  **"`Θ` 有实谱" ⟺ 零点在临界线上 ⟺ RH**。**公理 II 就是那个缺口。**
- 六条独立侦察线（变分 / 正性 / 造曲线 / λ‑运算 / THH‑Tate / 动力学）**全部收敛到同一格**。

全文后果均按 **严格 / 半严格 / 结构性** 三级标注（§7）。

## 0. 引子：为什么"朗兰兹"是一元论的实例

读解对象：Quanta Magazine, Natalie Wolchover《朗兰兹纲领：数学的大统一理论》（中译：梦溪湖笔记，2026-09-10）。

这篇文章的算术是干净的（完整算例 `x³ − 2 = 0` 逐步复算通过：模 31 的解 4/7/20、`4³¹ ≡ 4`、模 13 立方剩余 `{0,1,5,8,12}` 而 `2 ∉`）。

**它最深刻的一句**：「傅里叶分析的**非阿贝尔版本**」—— 因为它指向**机制**（可交换 ⟹ 系数是数；非交换 ⟹ 系数变矩阵）。
**它最危险的一句**：「同一个更深对象的**影子**」—— 那是本体论推测，不是定理。

**把它读成"一元"**：朗兰兹对应的两侧（自守 / 算术）**不是两个东西被证明相等，而是同一个量的两种记法** ——
这就是"一元（两本账）"。本篇的任务，是**给这个"一元"落位、并找出它在哪里断掉**。

## 1. 一元形态：朗兰兹对应 = 两本账

| 侧 | 记法 |
| :-- | :-- |
| **算术侧** | `L`-函数 / 欧拉积 / Frobenius 特征多项式 |
| **自守侧** | 自守表示 / 谱 / 迹公式 |
| **"两本账"的具体形式** | **显式公式**（数域）、**Lefschetz 迹公式**（函数域） |

**为什么这是"一元"而不是"对应"**：两侧**算的是同一个量**。
在函数域，这件事就是 Lefschetz 的有限和恒等式；在数域，就是 Weil 的显式公式。

> **"一元"（两本账）处处是定理** —— 这是整条链最稳的一句话（链上约 50 条定理级实例）。

---

## 2. 四条公理落位

| 公理 | 内容 | 在本实例中 |
| :-- | :-- | :-- |
| **I 存在** | 实体 ≡ 泛函 `F[ψ]` | `F` = **Weil 二次型**（`GL₁`）；正性 ⟺ RH |
| ★ **II 演化** | `δF = 0` | **Frobenius 流**（`Spec ℤ` 上的 `ℝ`-作用），生成元 `Θ`；`ζ(s) = det_reg(s − Θ)` |
| **III 精度** | `γ = ‖δ²F/δψ²‖_{S₁}` | **Schatten 范数** —— **是「定号型」记账** |
| **IV 对应** | 极限还原 / Γ-收敛 | 朗兰兹对应与公理 IV **同母题、不同子类** |

> **一句话**：`I` 给"一元"，`II` 给"演化"，`III` 给"定号"，`IV` 给"还原"。
> **在这条链上，卡住的是 `II`（见 §5）。**

---

## 3. 函数域：完整的实例（已证）

对曲线 `X/𝔽_q`：

| 环节 | 状态 |
| :-- | :-- |
| **两本账** | ✓ Lefschetz 迹公式 |
| **`F`** | ✓ **交形式** |
| **正性** | ✓ **Hodge 指标**（正性自动成立） |

**数值支撑**（本人实算，脚本留在工作区）：

- **曲线的 RH**：`|α| = √p` 在 **91 条曲线**上全部成立（机器精度）；
- **独立核验**：不去推断，**直接数 `𝔽_{p²}` 上的点**，与特征多项式预测一致（`p = 5`：27；`p = 7`：55）；
- **演化生成元**：`Θ = log(Frobenius)` 的谱落在直线 `Re = ½ log q` 上，**107/107** 成立（偏差 `2.2e-16`）。

> **⟹ 函数域是一个"闭合"的实例：两本账、`F`、正性、演化，四件齐备。**

---

## 4. 数域：缺口定位

**两本账在数域也存在**（Weil 显式公式，已证）。**缺的是正性。**

经过**十次修订**，缺口的表述逐步精确（见《总纲》§三），最终锁定为**一个格子**：

| | **零点结构**（`γ`、RH） | **特殊值**（`ζ` 在 `s=n`） |
| :-- | :-- | :-- |
| **有限域 / 函数域** | ✓ 已做（Hesselholt 2016） | ✓ 经典 |
| **`Spec ℤ` / 数域** | ✗ **空** | ✓ 已做（Morin–Flach 2024） |

> ### **这一格 —— `(Spec ℤ, 零点结构)` —— 就是缺口。**

**三条结构性障碍**（见 §7 分级）：

| 障碍 | 内容 |
| :-- | :-- |
| **值域** | `ℚ_p` **不可序、无相容正锥** ⟹ 这一侧**结构上产生不了定号** |
| **配对** | 数域的自然配对（Poincaré / Weil）是**交错型** ⟹ **恒不定号** |
| **两条 no-go** | **Serre**：不存在取值于**任何全序域**的 Weil 上同调；**Deninger 2022**：不存在**实系数** Weil 上同调 |

---

## 5. ★ 公理 II 的特殊位置：它就是缺口

**这是本篇最要紧的一节。**

"演化"（`δF = 0`）在本实例中**有确切的名字**：**Deninger 的 Frobenius 流**。

| 层次 | 内容 |
| :-- | :-- |
| **流** | `Spec ℤ` 上的 `ℝ`-作用（Deninger；Scholze 2023 报告亦复述） |
| **生成元 `Θ`** | `ζ(s) = det_reg(s − Θ)` —— **ζ 是"演化的谱行列式"** |
| ★ **周期轨道** | **每个 `Spec 𝔽_p` 是一条长度 `log p` 的闭轨** ⟹ **"`δF = 0` 的解"就是素数** |
| ★ **良定义** | "`Θ` 有实谱" ⟺ 零点在临界线上 ⟺ **RH** |

**两个情形**：

| 情形 | `Θ` 的谱 | 状态 |
| :-- | :-- | :-- |
| **函数域** | `Θ = log Frobenius`，`Re(log α) ≡ ½ log q`（谱在一条直线上） | ✓ 已证 + 本次实测 107/107 |
| **`Spec ℤ`** | 应为"谱在实轴上" | ✗ `Θ` 尚未造出 |

> ### **⟹ 公理体系里唯一卡住的那一条（II），正是这条链定位出来的那一格。**
> ### **不是"相关"，是同一件事。**

## 6. 六条侦察线的收敛

| # | 侦察线 | 出发点 | 结论 |
| --: | :-- | :-- | :-- |
| 1 | **变分** | 有没有作用量？ | 自守有、几何有、**算术无** |
| 2 | **正性** | 正性缺口在哪？ | 函数域闭合、数域开放 |
| 3 | **造曲线** | 谁造出了那条曲线？ | 三个人**各占一半** |
| 4 | **λ‑运算** | λ / Adams 与 `𝔽₁` 谁先接？ | 首次接口 = **Borger 2009**；CC 2020 已把它接到**算术 site** |
| 5 | **THH / Tate** | 同伦论那条线呢？ | FF 零点结构已做；`Spec ℤ` 只做了特殊值 |
| 6 | **动力学** | `δF = 0` 的演化是什么？ | Frobenius 流；**实谱 ⟺ RH** |

> ### **六条从完全不同的方向出发的侦察，收敛到同一条分界线：**
> # **函数域（已证） vs 数域（开放）**

## 9. 边界与不声称

**本文没有声称的**：

- 没有证明任何新的数学定理 —— 全部是**定位与综述**；
- 没有证明 RH；
- "朗兰兹对应 ≡ 公理 IV" 是**结构性对应**，不是等价定理；
- "一元"是一个**读法**，不是已证的分类定理；
- R / R2 的数值结果**不构成证明**（它们是数值实验）。
