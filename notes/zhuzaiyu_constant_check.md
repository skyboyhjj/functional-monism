# 公理IV续_常数耦合的核查（主动找反例）

> **承接**：`zhuzaiyu_two_books.md`　|　**分级**：见 §四
> **方法**：SOP S3「沙盘推演」中**唯一一步主动去找自己的反例**——整条链的转折点

---

## 一、出发点

文章声称：十二律"**耦合**"了黄金分割、斐波那契数列、柏拉图立体。
本侦察**专门去证伪**这个声称。

## 二、核查（脚本 `scripts/zhuzaiyu/verify.py` C/D/E 段）

### 2.1 φ（黄金分割）：不存在精确关系

- 数值：log2(φ) = 0.6942419136 ⟹ 律位 = **8.3309（非整数）**。
- 代数：φ 是二次代数数（x²−x−1=0）。若存在 2^(n/12)=φ，则 φ¹²=2^n——**左边仍是二次代数数，右边是有理数**，不可能。
- ⟹ **"姑洗=黄金分割点"是数值巧合**，不是结构关系。

### 2.2 斐波那契：不是同一序列

- 斐波那契相邻比 → φ ≈ 1.618；十二律比 → 2。
- 两者**不相等**，也无共同生成规则。所谓"耦合"只是"都出现于同一篇文章"。

### 2.3 三分损益（3/2）vs 十二平均律（2^(7/12)）

- 单步差 = **1.96 音分**；12 步累积 = **(3/2)¹²/2⁷ = 1.0136433 = 23.46 音分**（毕氏音差）。
- ⟹ **三分损益 12 步回不到八度**——这恰是朱载堉的历史要害：他用 2^(1/12) 把不可闭合的偏差**平均掉**。

## 三、结论（否定 + 重构）

**否定**：文章的三处"耦合"（φ / 斐波那契 / 柏拉图立体）**均不成立**为精确结构；φ 那条可整段证伪。

**重构**：那十二律的"**12**"到底从哪来？——来自**数论逼近**：

> **"12" = log2(3/2) 的连分数最佳逼近 p/q = 7/12 的分母。**

即：m 个纯五度（×3/2）≈ n 个八度（×2），最佳解 (m,n)=(7,12)。

## 四、分级

| 结论 | 分级 |
| :-- | :-- |
| φ / 斐波那契与十二律**无**精确关系 | **严格**（可代数证伪） |
| "12"源自 log2(3/2) 的连分数逼近 7/12 | **严格**（连分数论） |
| 柏拉图立体与十二律"耦合" | **需核实**（文章未给任何可算关系） |

## 五、对缺口表述的贡献

这一步做了两件事：

1. **砍掉了**原文最花哨的一层（φ / 柏拉图立体 / 斐波那契"耦合"）；
2. **补上了一个更硬的替代**——"12"来自数论逼近。

> 正如引擎所要求的：**每一次否定都不是推翻，而是把断言往下压一层，直到它落在一个可以动手算的地方。** 这里，"耦合"被压成了"连分数收敛项"。
