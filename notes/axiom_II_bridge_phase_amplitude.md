## 1. 离散↔连续 = 时间-1 映射（成熟，但"免费"须限定）

阴阳五行的**生** $`R`$（木→火→土→金→水→木，5 循环）可嵌入圆上的连续旋转流：

$$\phi_t(\theta)=\theta+72^\circ t,\qquad \phi_1=R.$$

脚本验证：$`\phi_1(\theta_i)=\theta_{R(i)}`$ 对所有 5 个元素成立（True）。

这是动力系统里"嵌入流"的标准机制：离散映射 $`f`$ ↔ 连续流 $`\phi_t`$，桥 = $`f=\phi_1`$（时间-1 映射）。

> **边界说明（"免费"只适用于旋转类，不可推广）**：一般离散映射要嵌入连续流（$`f=\phi_1`$）**有障碍**——一维映射须定向保持、无方向反转（反例 $`f(x)=1-x`$ 不能嵌入流）。"时间-1 映射免费"仅对**圆旋转 $`R`$ 这一特例**平凡成立（$`R`$ 本身就是旋转，等于直接就是流）。故"免费/通用"不能当作普适结论，实算通过的只是 $`R=\phi_1`$ 这一例。

## 2. 真正的缺口：保守↔耗散

两个实例"连续化"后**不是同一种演化**：

| 实例 | 连续化后 | 性质 |
| :-- | :-- | :-- |
| 阴阳五行（$`R`$） | 圆旋转 $`\dot\theta=\omega`$ | **保守**：无全局势（$`F(2\pi)-F(0)=-6.283\ne0`$）、等距、可逆 |
| 内感受（自由能 $`F`$） | 梯度流 $`\dot s=-\nabla F`$ | **耗散**：有势、$`F`$ 单调降、趋向吸引子、不可逆 |

保守↔耗散的桥 = 阻尼 $`\delta`$：$`\delta=0`$ 守恒（辛欧拉格式保能量），$`\delta>0`$ 耗散（衰减到吸引子）。

> 实际上圆旋转**不是**梯度流（势 $`F=-\omega\theta`$ 在圆上不单值）；自由能流是梯度流。⟹ **"离散生克"连续化成"保守流"，"内稳态"本身是"耗散流"——两者不是同一种演化。** 这才是"桥"里真正卡住的地方。

## 3. 圆上耗散化的拓扑障碍 $`H^1(S^1)=\mathbb R`$

圆旋转 $`\dot\theta=\omega`$ 的对偶 1-形式 $`d\theta`$ **闭但非恰当**：$`d(d\theta)=0`$，但 $`\oint_{S^1}d\theta=2\pi\ne0`$。**势存在 ⟺ 向量场恰当 ⟺ $`H^1=0`$**。圆上 $`H^1\ne0`$，所以纯旋转**无势**。

| 空间 | $`H^1`$ | 后果 |
| :-- | :-- | :-- |
| 实线 $`\mathbb R`$（一维） | $`0`$ | 一维自治流 $`\dot x=f(x)`$ 必有势（$`V=-\int f\,dx`$）⟹ 耗散**免费** |
| 圆 $`S^1`$ | $`\mathbb R\ne0`$ | 存在"纯旋转"（无势）⟹ 耗散**不免费**（须破坏拓扑性） |

> **边界说明（"有势"须限定一维）**：$`H^1(\mathbb R)=0`$ 只保证**一维**自治流都是梯度流；$`\mathbb R^n\,(n\ge2)`$ 上存在大量非梯度流（如哈密顿流、含旋转的向量场），"一切流都有势"不成立。此处"实线"严格指一维。

**解法 A（外场）**：加梯度项 $`\dot\theta=\omega-\delta\sin\theta`$（有势 $`F=-\delta\cos\theta`$），$`\delta>\omega`$ 时出现稳定不动点 $`\theta^*=\arcsin(\omega/\delta)`$——代价是**外场 δ**（打破旋转对称）。

**解法 B（补径向维度，Hopf / Stuart-Landau）**：把圆"加厚"成复平面 $`\mathbb C=\mathbb R_{\ge0}\times S^1`$（幅度 × 相位）：

$$\dot z=(\mu+i\omega)z-|z|^2z,\qquad z=re^{i\theta},$$

分离实虚得 $`\dot r=\mu r-r^3`$（径向：有势、耗散）与 $`\dot\theta=\omega`$（角向：无势、守恒）。**耗散发生在径向、守恒发生在角向**——内在，代价是**加一维**。

⟹ **圆上的耗散化 = 给圆补径向（幅度）维度。保守↔耗散的桥 = 相位↔幅度的桥（$`\mathbb C`$，即极坐标分解）。**

## 4. 五行 = 真相位

把五行（木火土金水）标为 0..4，从 TCM 文字关系**独立**构造两个置换：

- **生**（木生火、火生土、土生金、金生水、水生木）：5 循环 $`R=(0\,1\,2\,3\,4)`$；
- **克**（木克土、土克水、水克火、火克金、金克木）：$`0\to2\to4\to1\to3\to0`$。

独立比对（不预设）得出：

| 检验 | 结果 |
| :-- | :-- |
| 生 $`R`$ 是 5 循环（$`R^5=I`$） | ✓ |
| 生/克/侮/及母 = $`R^1/R^2/R^3/R^4`$（单一生成元） | ✓，且 **克 = 生²**（跳一格，独立比对成立） |
| 生 ∪ 克 = $`K_5`$（覆盖全部 10 对）、生 ∩ 克 = ∅ | ✓ |
| $`R`$ 特征值全在单位圆（$`\lvert\lambda\rvert=1`$）、$`\det R=+1`$ | ✓（等距、真旋转、无内禀耗散方向） |

**判别力只来自"生/克互补"这一条**：5 个点上，5 循环的边集补必是另一个 5 循环且恰为 $`R^2`$（定理）。所以"生、克互补 ⟹ 克 = 生² ⟹ 单一生成元"。其余几项（5 循环、等距、放圆上）**任何 5 循环都满足**，无判别力。

⟹ **五行 = 单一生成元的 $`\mathbb Z_5`$ 相位结构，内在、标签无关，是"真相位"；且与公理 II 的"保守侧"对齐（"五行 = 保守 = 相位"）。**

## 5. 组装：κ z̄⁴ + 五次饱和（可行但不免费）

最小组装 $`\dot z=(\mu+i\omega)z-|z|^2z`$ 只是 $`\mathbb C=\mathbb R_{\ge0}\times S^1`$ 的**解耦并置**（相位与幅度各自独立）。真组装需加**保持 $`\mathbb Z_5`$ 对称**的耦合项，最低阶是 $`\kappa\bar z^4`$：

- 检验：$`\bar z^4`$ 在 $`z\to\omega z`$（$`\omega=e^{2\pi i/5}`$）下变换因子 = $`\omega`$，与 $`z`$ 同变换 ✓；
- 所以 $`\kappa\bar z^4`$ 保持 $`\mathbb Z_5`$ 对称——是合法的相位-幅度耦合（复 GL 的 5 次共振项）。

它使：

$$\dot\theta=\omega-\kappa r^3\sin(5\theta),\qquad \dot r=\mu r-r^3+\kappa r^4\cos(5\theta).$$

**但单独的 $`\kappa\bar z^4`$ 会发散**：四次项在 $`r`$ 方程里是 $`+\kappa r^4\cos5\theta`$，**无饱和**，当 $`\cos5\theta>0`$ 时把 $`r`$ 推爆（复 GL 里 $`m`$ 次共振项 $`\bar z^{m-1}`$ 破稳的经典性质）。

**配五次饱和 $`-\delta|z|^4z`$ 后成立**：

| κ | δ | 终态 |
| :-- | :-- | :-- |
| 2.0 | 0.0 | ✗ 发散 |
| 2.0 | 1.0 | 锁相，距 72° 倍数约 $`1.4°`$ |
| 4.0 | 1.0 | 锁相，距 72° 倍数约 $`0.1°`$ |

⟹ **幅度（内感受）把相位（五行）钉到 5 个离散值（72° 倍数）**；实测距 72° 倍数**随 κ 而定**（κ 越大钉得越准，不是固定 0.1°）。

**四层"不免费"**：

| 层 | 额外结构 |
| :-- | :-- |
| 加维 | $`S^1\to\mathbb C`$（圆上加径向） |
| 选耦合 | 必须 $`\mathbb Z_5`$-等变（否则破对称） |
| 配饱和 | 必须加 $`-\delta\lvert z\rvert^4z`$（否则发散） |
| 容忍偏移 | 钉住点有偏移 $`\arcsin(\omega/\kappa r^3)/5`$（$`\kappa\to\infty`$ 才 exact 72°） |

## 6. κ 从哪来：U(1)→Z₅，离散性的接口（公理 III）

检验 $`\dot z=(\mu+i\omega)z-|z|^2z+\kappa\bar z^4`$ 在 $`z\to e^{i\alpha}z`$ 下是否等变：

| κ | 一般 $`\alpha=0.9`$ | $`\alpha=2\pi/5`$ |
| :-- | :-- | :-- |
| 0.0 | 等变 ✓（连续 $`U(1)`$） | 等变 ✓ |
| 1.0 | **不等变** ✗ | 等变 ✓（离散 $`\mathbb Z_5`$） |

⟹ **$`\kappa\bar z^4`$ 把 $`U(1)`$（连续相位）破缺到 $`\mathbb Z_5`$（离散相位）**。相位方程 $`\dot\theta=\omega-\kappa r^3\sin(5\theta)`$ 里，κ 就是 5 个势阱的深度：κ=0 无势阱、连续旋转、五行"消失"；κ>0 锁相、5 相位"出现"。**κ 字面意义上"开关"了五行。**

三层来源（嵌套，非竞争）：

| 层 | κ 是什么 | 能否推导 |
| :-- | :-- | :-- |
| 表层 | 相位与幅度的耦合强度 | 命名 |
| 中层 | $`\kappa\bar z^4`$ 的 5 次形式来自"五行有 5 个元素" | 形式可定，强度不可 |
| **深层** | $`\kappa\bar z^4`$ 把 $`U(1)\to\mathbb Z_5`$ ⟹ κ 是**离散性**的作用强度 | **不能**——离散性 = 公理 III 的精度商面（提法三） |

⟹ **κ 不能在公理 II 内部推出**：$`U(1)`$ 是公理 II 连续演化的对称，而 $`\bar z^4`$ 在它**外面**。**公理 II 的桥要搭，必须借公理 III——精确地说，借它的「精度商」提法。**

**公理 III 落点**：公理 III 现有**三提法**——一、曲率版（有限维 $`\gamma=\mathrm{Tr}\,H`$，见 [axiom_III_curvature](../axioms/axiom_III_curvature.md)）；二、重整化版（连续极限 $`\gamma_{\text{ren}}=\zeta_{D^2}(-1/2)`$，见 [axiom_III_IV_gamma_regularity_and_eta](axiom_III_IV_gamma_regularity_and_eta.md)）；三、精度商版（信息面 $`\gamma=\sum_i\epsilon_i^{-2}`$，见 [axiom_III_precision_quotient](axiom_III_precision_quotient.md)）；另有**派生**拓扑面，见 [axiom_III_topological_face](axiom_III_topological_face.md)。本节 $`\kappa`$ 精确接入**提法三**：

| 提法 | 与 κ 的关系 |
| :-- | :-- |
| **三·精度商（信息面）** | **κ = 精度商 $`S^1\to\mathbb Z_5`$ 的强度**（演化被精度截断）；$`U(1)\to\mathbb Z_5`$ 正是「精度商把连续对称收缩为离散」的实例 |
| 一·曲率（有限维） | 间接：与精度商同体（$`\lambda_i=\epsilon_i^{-2}`$，Cramér–Rao），但 κ 本义落在精度商侧 |
| 二·重整化（连续极限） | **尚未接通**：重整化 ↔ 信息只到机制类比（减发散取有限 ⟺ 有限→无限不免费），无定量等式 |

⟹ 「κ 来自公理 III」的精确读法：**κ 是公理 III 精度商面上 $`S^1\to\mathbb Z_5`$ 这个商映射的强度——不是「公理 III 一片空白」，而是此前没把 κ 落到精度商这条接法上。**

## 7. 全链结论

| 环节 | 结论 |
| :-- | :-- |
| 离散↔连续 | ★ 成熟（时间-1 映射 $`f=\phi_1`$，仅旋转类免费） |
| 保守↔耗散 | ✗ **缺**——这才是缺口 |
| 圆上耗散化 | 拓扑障碍 $`H^1(S^1)=\mathbb R`$ → 补径向 |
| 五行 = 相位 | ✓ 通过 |
| 组装（相位+幅度） | ✓ 可行但不免费 |
| κ 从哪来 | 离散性的接口（公理 III） |

**"公理 II 的桥"缺，根子不在"公理 III 空白"（它已有三提法），而在 κ 只接住了精度商这一面、且「重整化 ↔ 信息」这条边未定量闭合。**

## 8. "X 免费、Y 不免费"格式（跨实例同型）

| 实例 | 免费 | 不免费 |
| :-- | :-- | :-- |
| 朗兰兹 | 恒等式 | 符号（正性） |
| 哈密顿 | 守恒（辛流） | 正定 |
| p 进 | $`\le`$（收缩/因果） | $`=`$（等距/可逆） |
| 公理 II 离散↔连续 | 时间-1 映射（旋转类） | — |
| **公理 II 保守↔耗散** | **角向旋转（实线上）** | **径向耗散（圆上）** |

> 措辞注意：这里的"免费/不免费"是关于"**势是否存在**"，与 p 进那条（关于"因果方向是否强加"）**口径不同**，只登记为"同型格式"，不合并含义。

## 9. 诚实边界

- 「五行 = 相位」**通过**，但判别力只来自一条（生/克互补）；且「生/克互补是发现的还是定义的」**未定**。
- 组装是**存在性**（一个可行组装），**不是唯一/必然**；耦合是**选的**，不是推的；幅度方程取 SL 型，内感受自由能**未被证明**就是 SL。
- 「κ 接公理 III（精度商面）」是**接口分类判断**，不是从公理 III 推导出 κ 的强度值；κ 的来源是**结构定位**，不是物理推导。
- 公理 III 三提法里「重整化 ↔ 信息」这条边**仅到机制类比、未定量闭合**——κ 接的精度商面与连续极限重整化一侧的定量关系仍缺。
