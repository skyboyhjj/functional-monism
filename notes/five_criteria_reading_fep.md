## 二、逐条核验

### 2.1 第一层的公式：重建并数值验证 —— **严格** ✓

文中该公式以**图片**给出（我这边提取时丢失），据其文字主张重建：

$$ F[q]=\mathbb E_q[\log q-\log p(o,s)]=\mathrm{KL}\!\left(q\,\|\,p(s|o)\right)-\log p(o)\ \ge\ -\log p(o) $$

**算据 A**（高斯模型闭式）：

| 检查 | 结果 |
| :-- | :-- |
| 恒等式 $`F[q]=\mathrm{KL}(q\|p(s\|o))-\log p(o)`$ | 最大偏差 $`3.55\times10^{-15}`$ ✓ |
| 不等式 $`F[q]\ge-\log p(o)`$ 全域 | 无违例 ✓ |
| 等号 $`\iff q=`$ 真后验 | 数值最小点 $`(\mu,\tau^2)=(0.90,0.45)`$，真值 $`(0.8564,0.4983)`$ ✓（差在网格分辨率内） |

⟹ **是标准 ELBO 事实，重建无误**。且文中紧接着的自我限定也对：这一步本身**中立**，把它读作"系统在最小化 $`F`$"才引入**梯度流假设**（属解释，非数学）。

### 2.2 complete class theorem 的转述：**过强** ◐

文中（§四·规范性问题）："对于**任意**一对损失函数和**决策**，都存在某些先验使该决策成为最优。"

**标准版本**（Wald 1950；Blackwell–Girshick）是：

> **可容许**（admissible）的决策规则 $`\Longrightarrow`$ 是某个（可能非正常）先验下的 **Bayes** 规则。

**算据 B**（反例）：取 $`\theta\in\{-1,+1\}`$、平方损失 $`(a-\theta)^2`$、$`x\sim N(\theta,1)`$，候选决策 $`\delta(x)\equiv 5`$：

| 先验 $`\pi(\theta=+1)`$ | Bayes 风险 | $`\delta\equiv5`$ 的风险 |
| :-- | :-- | :-- |
| 0.00 | 0.0000 | 36.0000 |
| 0.25 | 0.3662 | 31.0000 |
| 0.50 | 0.4496 | 26.0000 |
| 0.75 | 0.3662 | 21.0000 |
| 1.00 | 0.0000 | 16.0000 |

> **21 个先验（含退化 $`\pi=0,1`$）全部：$`\delta\equiv5`$ 的风险严格大于 Bayes 风险** ⟹ 它在**任何**先验下都不是最优。
> 结构理由一句话：Bayes 动作必为后验均值 $`\mathbb E[\theta|x]\in[-1,1]`$；常数 $`5`$ 永不等于它。
> 对照：$`\delta\equiv\pm1`$ **是**（退化先验下）Bayes ✓ —— 可容许类因此非空。

**溯源（不苛责）**：这个松散说法**在 FEP 文献内部就是这么流传的** ——
FEP 教材（Parr–Pezzulo–Friston, *Active Inference*）原文即写 "any statistical decision procedure (i.e., behavior) may be framed as Bayes optimal under the right set of prior beliefs (Wald 1947)"。
⟹ 文章是**忠实转述**，但按标准定理，它**少了"可容许"三个字**。

**影响评估（不夸大）**：文章由此推出的结论——"偏好先验不携带内在规范性内容"——在**弱版**（可容许 ⟹ 某先验下 Bayes）下**依然成立**，因为弱版已足以说明"Bayes 最优性是很廉价的约束"。
⟹ **论点不受致命影响，但引用须加限定。**

## 三、接口：与本项目「自由能／主动推断」一元实例对接（本文重点）

### 3.1 同一断点（最有价值的一条）

| | 本文（FEP 批评侧） | 本项目（内感受 AI 实例侧） |
| :-- | :-- | :-- |
| 那条线 | **给定状态空间内的变形** ｜ **空间本身的变形** | **框架层** ｜ **机制层（内稳态是否真进入动力学）** |
| 判据 | 五条形式标准（维度／拓扑／范畴／类型／动力学） | **势整形定理**：$`\gamma=1`$ 势整形**不改变最优策略**（Ng et al. 1999 + 自造算例） |
| 结论 | 五层数学均不满足 ⟹ 停在"给定空间内" | 框架齐（公理 I 单一泛函 $`F`$ ＋ 公理 III 精度）、**机制未落地**，缺口卡在**公理 II** |

> ⟹ **两者划的是同一条线**：本文叫它"空间生成"，项目叫它"内生性"。
> 而**项目侧的表述更可操作** —— 因为它有一个可算的判据（势整形定理），本文只有五条形式标准。

**可直接搬运（归功于本文）**：那**五条形式标准**可作为项目里"机制是否落地"的**形式判据** ——
问"内稳态进入动力学"是否达到了"状态空间扩展"，就逐条问：维度变了吗？拓扑变了吗？范畴换了吗？类型宇宙扩了吗？动力学定性变了吗？

### 3.2 方法论共振

本文 §7.4 的**自觉三档标注** ↔ 项目 `math-doc-rigor` 的**严格／半严格／结构性** —— 同一种纪律（§2.3 已述）。

### 3.3 真正的分歧：**对撞点**

| | 本文 | 泛函一元论 |
| :-- | :-- | :-- |
| 结论 | 谱系中**不存在**那个统一本体 ⟹ **降格为工具箱** | **去找**那个一元（单一泛函 ＋ 两本账） |
| 方向 | **拆统一** | **找统一** |

> 这不是谁对谁错，而是对"一元是否存在"的**立场分歧** —— 正是"反者道之动"要处理的那种对撞。
> **但有一个可吸收的空间**：本文反对的是"**某一个数学分支**能统一"（"试图用一个数学本体覆盖所有层级，而谱系中不存在这样一个本体"），
> 而项目主张的是"**一个判据量／单一泛函**"的统一（$`F`$ 存在、两本账同源）。**它反对的靶子与前者的靶子并不相同。**

⚠ **纪律**：以上均为**结构性对位**，**不是**等价（承 `09-并账检验`）。
**尤其不得**把"本项目公理 II 缺口"写成"证明了本文的结论"，也不得把"两处划同一条线"写成"两处是同一件事"。
