# 公理 IV · 已证样板章：十二律的完整一元

**——函数域之于朗兰兹、几何之于毕氏螺旋；十二律之于「音律-数论」**

> **一句话**：十二律在**数学层面**是一个**完整的**一元 —— **两本账、母结构、单一生成元，三件齐备，且严格**。
> **分级**：严格（本文不作"大一统"声称，只做结构陈述）。

---

## 一、三要件

| 要件 | 十二律里是什么 | 分级 |
| :-- | :-- | :-- |
| **两本账** | 大数递推（离散 / 算法侧） ↔ 复指数 z(t)（连续 / 解析侧） | 严格 |
| **母结构 F** | 循环群 **ℤ₁₂** 在频率对数轴上的自由作用 | 严格 |
| **单一生成元** | **2^(1/12)**（整个律阶 = ⟨2^(1/12)⟩） | 严格 |

对照：朗兰兹的样板是"函数域"（两本账 + F + 正性齐备）；毕氏螺旋的样板是"五角星层级步"（缩放∘旋转）。十二律的样板就是它自己 —— 一个**干净的循环 × 标度结构**。

## 二、群结构（母结构）

把频率取对数、以八度为模：

$$x=\log_2 f \pmod 1,\qquad \text{十二律}=\tfrac{1}{12}\mathbb{Z}\big/\mathbb{Z}\;\cong\;\mathbb{Z}_{12}$$

相邻比恒为 2^(1/12)；乘性封闭

$$2^{a/12}\cdot 2^{b/12}=2^{(a+b)/12}$$

即**比值构成循环群 ℤ₁₂（模八度）**。其连续化就是那条**对数螺旋**：

$$z(t)=\exp\!\Big(t\big(\tfrac{\ln 2}{12}+\tfrac{2\pi i}{12}\big)\Big)$$

半径按 2^(1/12) 伸缩、极角每律转 30° —— **缩放 ∘ 旋转**。

## 三、两本账（本样板章的"正性"对应物）

| :-- | :-- | :-- |

| 类型 | 算法（可算） | 公式（可解析） |

**逐点对齐**（`scripts/zhuzaiyu/verify.py` B 段）：

$$2^{n/12}\cdot e^{2\pi i n/12}=\exp\!\Big(n\big(\tfrac{\ln 2}{12}+\tfrac{2\pi i}{12}\big)\Big),\qquad n=0,\dots,12$$

> 离散递推**就是**连续螺旋在整点的采样。这就是"两本账"的标准形态，与朗兰兹（算术侧 ↔ 谱侧）同母题。

## 四、"12"的来源（母结构的**参数**从哪来）

十二律的"**12**"不是任意的，它来自**数论逼近**：

> **"12" = log2(3/2) 的连分数最佳逼近 p/q = 7/12 的分母。**

- log2(3/2) = 0.5849625007…，连分数 [0; 1, 1, 2, 2, 3, 1, 5]；
- 收敛项 … → 3/5 → **7/12**（误差 **1.955 音分**）→ 24/41 → …；
- 含义：m 个纯五度（×3/2）≈ n 个八度（×2），最佳解 (m,n)=(7,12)。

**历史要害**：三分损益（纯五度链）12 步累积偏差 = **(3/2)¹²/2⁷ = 毕氏音差 = 23.46 音分**，回不到八度；朱载堉用 2^(1/12) 把偏差**平均**掉 —— 十二平均律是对"纯五度不可闭合"的**否定**。

> 所以"12"有**两层**理由，需并记：**数论理由**（连分数逼近，严格）与**设计理由**（12 的因数多，便于转调 —— 属设计/工程层，本文不声称其为数学定理）。
