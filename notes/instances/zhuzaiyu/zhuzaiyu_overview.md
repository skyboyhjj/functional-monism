# 总纲：从「朱载堉十二律」到「一元形态」的定位

**——一次实例化的侦察链记录**

> **起因**：2026-09-19，从一篇公众号文章（大明历正《朱载堉算法番译三角函数、欧拉公式、棣莫弗公式、斐波那契数列》）开始。
> **结论**：它是一个**真的一元实例**——「音律-数论」实例；但它的**缺口与朗兰兹相反**：**数学满格，解释越界**。
> **分级原则**：严格 / 半严格（数值）/ 结构性 / 需核实

## 〇、一页速览（结论先行）

| 问题 | 答案 |
| :-- | :-- |
| **起点** | 一篇把朱载堉十二律"翻译"成现代复分析的公众号文 |
| **它引出的问题** | 十二律的生成，是不是一个"一元（两本账）"？ |
| **发现** | **是**：离散递推（账 A）与连续螺旋（账 B）算的是同一个量 |
| **母结构 F** | 循环群 **ℤ₁₂** 在频率对数轴上的自由作用；单一生成元 2^(1/12) |
| **它的"两本账"** | 账 A = 大数递推（算法侧）｜账 B = 复指数 z(t)（解析侧） |
| **原文的三处过度声称** | φ 耦合（可证伪）、斐波那契耦合（不成立）、"大一统"（不可证伪） |
| **★ 更硬的替代** | "**12**"来自 **log2(3/2) 的连分数逼近 7/12**，不是 φ / 柏拉图立体 |
| **★ 最终定位** | 「音律-数论」一元实例，对应**公理 IV**（对应：离散 ⟷ 连续） |
| **★ 缺口在哪** | **不在数学**（数学满格），在 **"结构 → 解释"的那一跳** |

> **一句话**：
> **十二律真的是"一元"；但它缺的不是数学，而是"从结构到解释"的那座桥——原文没搭，就直接说了"大一统"。**

## 五、三级标注总表

### 5.1 严格
1. 十二律比 = 2^(n/12)，比值群 ≅ ℤ₁₂（模八度）。
2. 离散递推 = 连续螺旋 z(t)=exp(t(ln2/12 + 2πi/12)) 的整点采样。
3. "12" = log2(3/2) 的连分数逼近 p/q = 7/12 的分母。
4. φ 与十二律**无**精确关系（φ 二次、2^(n/12) 非二次）。
5. 三分损益 12 步累积偏差 = 毕氏音差 23.46 音分。

### 5.2 半严格（数值）
1. 勾股律管 10√2 / 5√2、密率 355/113、十二律各比值（本次实算）。
2. 单步 3/2 与 2^(7/12) 之差 1.96 音分。

### 5.3 结构性
1. "十二律 = 极坐标 FFT"（形态类比，非同一对象）。
2. "天地坐标系 / 时空频域图"（一种读法）。

### 5.4 需核实 / 不构成命题
1. "律管 = 内存条、存储程序雏形"（隐喻，无可算对应）。
2. "东西方算学大一统"（不可证伪，不构成数学命题）。

> **禁止事项**：不得把 5.3 / 5.4 里任何一条写成"严格等价"或"就是"。

## 六、与另两个实例的对照

| | 阴阳五行（象数） | 朗兰兹（数学） | **朱载堉十二律（音律-数论）** |
| :-- | :-- | :-- | :-- |
| 母结构 | F[ψ]，ℤ₁₀ | 两本账 | ℤ₁₂ ×（对数标度） |
| 一元形态 | 同一对称群的两种读法 | 自守/算术两种记法 | 离散/连续两种记法 |
| 公理 I（存在） | 单一泛函 F | Weil 二次型 | 群作用 z(t) |
| 公理 II（演化） | 非线性 Schrödinger | Frobenius 流 Θ | 旋转∘伸缩（生成元 2^(1/12)） |
| 公理 III（精度） | γ = Tr Hess F | Schatten 范数 | π 逼近 / 大数定点 |
| 公理 IV（对应） | 连续极限 | 朗兰兹对应 | **离散 ⟷ 连续** |
| **缺口类型** | 缺口在公理 II | **数学缺一格**（正性） | **数学满格，解释越界** |
| 状态 | 相图有精确解 | 函数域已证 / 数域缺口 | 结构已证 / 解释待分级 |

> **三个实例，同一个母题**（"一元 = 两本账"），但**缺口的位置各不相同**——这本身就是最强的结构性线索。

## 七、边界（本总纲不声称什么）

- 不声称证明了新定理；本文是**定位与分级**。
- 不声称"朱载堉 = 现代数学"（这是原文的声称，本文把它降级为"两本账"）。
- 不声称原文全错——它的**机制主线是对的**。
- 不声称"12"的来源仅有连分数一条（转调便利 / 因数丰富是**设计**层面的理由，与数论理由并存）。
