## 0. 一句话

在「泛函一元论」总纲里，那个被反复定位为「**缺的是正性，不是连接**」的缺口，可以分解为三层：**① 信息不缺 / ② 构造缺 / ③ 正性缺**。本文做的是一件事——把<strong>②层（构造层）</strong>对齐到数学里一个现成的机器：**层上同调 ＋ 谱序列**。做法是：先澄清「断点」的精确性质（不是信息论式，而是「装配 ＋ 正性」式），再以 Connes 的 Scaling Site 为样本，把它逐字核查到定理级——**②层在 Scaling Site 上已经做完（有定理、有 Riemann–Roch）**，但**③层不被它推进**，因为该实现把「临界线」当作输入。

## 1. 断点性质的澄清 —— 不是「信息不足」，而是「装配 ＋ 正性」

> 方法：先算后说（脚本 `explore_local_vs_global.py`）。本部分是「三层缺口」三个层次最初被写下处。

### 1.1 先修正一个早先的错误表述

早先曾写：「断点的性质是**信息论式**的——局部因子原则上不足以决定整体零点位置。」**这句话不准确，必须修正。** 核验如下。

### 1.2 到底缺的是不是「信息」？

**A 有限域侧——装配是自动的。** 对 $`E:y^2=x^3-x`$：

| $`p`$ | $`a_p`$ | $`P(T)`$ 的根 $`T`$ | $`\lvert T\rvert`$ | $`1/\sqrt p`$ |
| ---: | ---: | :-- | ---: | ---: |
| 101 | $`-2`$ | $`-0.00990099 \pm 0.09900990\,i`$ | 0.099503719 | 0.099503719 |
| 1009 | $`-30`$ | $`-0.01486620 \pm 0.02775025\,i`$ | 0.031481428 | 0.031481428 |

⟹ 零点 = 一个**次数固定**的多项式的根：有限、可直接写出。**局部数据 ⟹ 整体，这一步不需要额外构造。**

**B 数域侧——Newton 恒等式确实起不动。** 取 ζ 的前 300 个零点实算幂和 $`S_{2n} = \sum_\gamma \gamma^{2n}`$：

| $`n`$ | 1 | 2 | 3 | 4 |
| ---: | ---: | ---: | ---: | ---: |
| $`S_{2n}`$ | 3.51×10⁷ | 6.41×10¹² | 1.37×10¹⁸ | 3.17×10²³ |

而理论值：零点密度 $`\sim \frac{\log T}{2\pi}`$，故

$$\sum_\gamma \gamma^{2n} \;\sim\; \int_0^\infty T^{2n}\cdot\frac{\log T}{2\pi}\,dT \;\longrightarrow\; \infty$$

⟹ 幂和发散 ⟹ Newton 恒等式**无法启动** ⟹ **不存在有限次的特征多项式**。

**C 但这是「信息不足」吗？不是。** 理由（关键的逻辑澄清）：

> **收敛域内的值，唯一确定解析延拓**（若延拓存在）。而 Euler 积在 $`\mathrm{Re}(s)>1`$ 完全给出了 $`L`$ 的值。
> ⟹ **理论上，局部数据完全决定整个 $`L`$（含零点）——信息并不缺。**

况且两侧的「信息量」都是**可数无穷**（局部：$`\{a_p\}`$；整体：$`\{\gamma_k\}`$），量级相当。**所以「信息论式」是错的。**

### 1.3 断点的三层结构（本轮分析的核心）

| 层次 | 内容 | 状态 |
| :-- | :-- | :-- |
| **① 信息层** | 局部数据 ⟹ 整体（含零点） | ✓ **不缺**（靠唯一延拓） |
| **② 构造层** | 把零点**实现为**某个整体对象（流/算子/圆作用）的**谱** | ✗ **缺** |
| **③ 正性层** | 该对象**自伴 / 正定** ⟹ 谱为实 ⟹ RH | ✗ **缺** |

> **第 ③ 层正是总纲所说的「正性」。** 总纲那句「缺的是正性，不是连接」，由此得到最具体的三层分解。

**为什么第 ② 层必要？** 因为「零点在哪」是一个事实，而「零点为什么在那儿」需要一个结构性理由。数值验证（已能算到 $`10^{13}`$ 个零点）**不能**证明 RH，只能提供证据。要把 RH 变成**结构性命题**，唯一已知的框架是：

$$\mathrm{zeros} = \mathrm{Spec}(A),\qquad A = A^{*} \;\Longrightarrow\; \mathrm{Spec}(A)\subset\mathbb{R} \;\Longrightarrow\; \mathrm{Re}(s) = \tfrac12$$

这就是 Hilbert–Pólya 猜想的精神——也是 Deninger / Connes / Hesselholt 三条路线共享的母题。

### 1.4 三条「整体层」路线 = 三种装配方案

| 路线 | 装配成什么 | 它替代了什么 | 缺什么 |
| :-- | :-- | :-- | :-- |
| **Deninger** | Frobenius 流 $`\Theta`$ 的正则化行列式 $`\zeta = \det_{\mathrm{reg}}(s-\Theta)`$ | 无穷多个逐素数 Frobenius | 流所在的空间 |
| **Connes** | adele class space 上的 scaling 算子 + 迹公式 | 无穷 Euler 积 | **正性**（Weil 正性） |
| **Hesselholt** | THH 的 $`S^1`$-作用之 **Tate 构造** $`TP`$ | 商掉 Frobenius 的做法 | 在 Spec ℤ 上的构造 |

**共同点**：都用<strong>【一个整体作用】</strong>替代<strong>【无穷多个局部 Frobenius】</strong>——因为只有整体对象才能承载「零点位置」这种整体信息，而局部拼接恰在此失效（核验 B）。

**为什么 Connes 那条路最「贴题」**：Connes 把零点实现为 scaling 算子的谱，而**证明谱为实**需要 **Weil 正性（positivity）**——这正是总纲定位的缺口（「序的正性」 ⟹ 「定号的正性」）。三条路线里，只有它把「正性」**显式**写成前提。

### 1.5 连带的两个解释

1. **为什么 Grönwall / Chebyshev 那样的初等工具不够？** 因为它们只处理**局部/有限**信息（素数计数主项 $`\pi(x)\sim x/\log x`$），而零点位置是**整体延拓对象**的性质，属于第 ② 层，初等工具够不到。
2. **为什么「$`\sum\gamma^{2n}`$ 发散 ⟹ Newton 无从启动」？** 因为 Newton 恒等式是**有限维**工具。数域侧对象是**无穷维**的，必须换成算子/流。

### 1.6 结论（修正后的准确表述）

> **断点不是「信息不足」，而是：② 缺一个使零点成为其「谱」的整体对象；③ 缺使该谱为实的正性条件。**
> 上一轮的「信息论式」应改为「**装配 ＋ 正性**式」：局部数据并不缺（唯一延拓就够），缺的是**把局部装成一个整体作用**，以及**让这个作用的谱落在实轴上**。

## 2. Connes 路线 —— 把 RH 化为「谱的实性」

> 方法：先取原文、再核验（脚本 `explore_connes_path.py`）。

### 2.1 为什么这条线最「贴题」

在三条「整体层对象」路线里，只有 Connes 这条把「正性」显式写成前提：

| 路线 | 整体对象 | 正性出现的位置 |
| :-- | :-- | :-- |
| Deninger | Frobenius 流 $`\Theta`$ | 隐含（「$`\Theta`$ 有实谱」） |
| **Connes** | **adele class space 上的 scaling 算子 + 迹公式** | **显式：Weil 正性判据** |
| Hesselholt | $`TP = THH^{tS^1}`$ | 隐含 |

### 2.2 核心构造：三件套

**① 空间：adele class space（非交换空间）**

$$\mathbb{Q}^\times \backslash \mathbb{A}_{\mathbb{Q}} \qquad\rightsquigarrow\qquad \mathcal{A} := \mathcal{S}(\mathbb{A}_{\mathbb{Q}}) \rtimes \mathbb{Q}^\times$$

Connes–Consani–Marcolli 的原句点破了关键：**「Scaling as Frobenius in characteristic zero」**（scaling 就是特征零中的 Frobenius）。

> ⟹ 这正是上一章所说「用【一个整体作用】替代【无穷多个局部 Frobenius】」——在特征零里，「乘 $`\lambda`$」扮演了「$`x\mapsto x^p`$」的角色。

**② 作用：scaling 流 $`H = x\partial_x`$**

$$\Delta \;=\; H(1+H), \qquad H = x\partial_x$$

**③ 装配：trace map $`\mathcal{E}`$**

$$\mathcal{E}f(u) \;=\; u^{1/2}\sum_{n>0} f(nu)$$

它在 Hochschild 同调里就是 trace map（$`\mathcal{E}(f)(u)=\tfrac{u^{1/2}}{2}\mathrm{Tr}(\tilde f)(u)`$），且满足一条把「局部」变成「整体」的积分恒等式：

$$\int_{\mathbb{R}_+^*}\mathcal{E}(f)(u)\,u^{-iz}\,d^*u \;=\; \zeta\!\left(\tfrac12 - iz\right)\psi(z)$$

> ⟹ 左边全是局部数据（$`f`$ 与整数 $`n`$），右边是 ζ。**这一步就是「装配」。**

### 2.3 两种谱实现（都已在文献中给出）

| 实现 | 承载对象 | 谱是什么 |
| :-- | :-- | :-- |
| **① 全部非平凡零点** | $`\Delta = H(1+H)`$ 在强 Schwartz 空间商上的作用 | $`\{(z-\tfrac12)^2 - \tfrac14 \mid \zeta(z)=0,\ z\notin\mathbb{R}\}`$ |
| **② 只临界零点** | **Scaling Site** $`\mathscr{S}=[0,\infty)\rtimes\mathbb{N}^\times`$ 上的**层上同调** $`H^0(\mathscr{S},\mathcal{L}^2/\overline{\Sigma\mathcal{E}})`$ | 临界零点的虚部 |

### 2.4 ζ-cycle：把零点装进「圆」

设 $`\mu>1`$，$`L=\log\mu`$，圆 $`C_\mu=\mathbb{R}_+^*/\mu^{\mathbb{Z}}`$。对满足 $`f(0)=0`$ 的偶 Schwartz 函数定义

$$(\Sigma_\mu g)(u)=\sum_{k\in\mathbb{Z}} g(\mu^k u), \qquad (\mathcal{E}f)(u)=u^{1/2}\sum_{n>0}f(nu)$$

> **ζ-cycle** 就是一个长度 $`L=\log\mu`$ 的圆 $`C`$，其 $`L^2(C)`$ 含 $`\Sigma_\mu\mathcal{E}(\mathcal{S}^{\rm ev}_0)`$ 作为**非稠密**子空间。

**定理（Connes–Consani）**：在该正交补上，$`\mathbb{R}_+^*`$ 作用的谱包含于临界零点的虚部；且若 $`\zeta(1/2+is)=0`$，则长度 $`2\pi/s`$ 的整数倍圆都是 ζ-cycle。

> ★ 这与总纲的缺口表述完全对上：总纲写「把 $`B^{\varphi=p}`$（p-adic 侧、序）下降到**周期轨道 $`C_p`$**，再与 adele class space 的迹型耦合」——那个 $`C_p`$ 正是 ζ-cycle 的圆 $`C_\mu`$，其长度 $`L=\log\mu`$。

### 2.5 正性出现在哪里（本路线的关键）

$$\text{RH} \iff \mathrm{Spec}(\Delta) \subset \mathbb{R}$$

因为 $`z=\beta+i\gamma \Rightarrow \lambda=(z-\tfrac12)^2-\tfrac14`$，其虚部 $`\mathrm{Im}\lambda = 2(\beta-\tfrac12)\gamma`$，故

$$\lambda \in \mathbb{R} \iff \beta = \tfrac12$$

而 $`\beta=\tfrac12`$ 时 $`\lambda = -\gamma^2-\tfrac14 \le -\tfrac14`$（**实且严格为负**）。于是 **RH 被化为「某个自伴算子的谱落在实轴上」**——这正是 Hilbert–Pólya 式陈述。

**Weil 正性**是这一步的分析形态：Weil 证函数域 RH 的核心是 **Riemann–Roch 给出的正性**；Connes 的策略（「Riemann–Roch strategy」，含 tropical descent）就是在特征零复制 Weil 的证明。

### 2.6 核验（本次实算）

| 项 | 结果 |
| :-- | :-- |
| ① 临界零点的 $`\lambda`$ 值 | $`z_1\Rightarrow\lambda=-200.0405`$；…；$`z_7\Rightarrow\lambda=-1674.5916`$，**全为实且 $`\le-1/4`$** ✓ |
| ①' 非临界零点 | $`\beta=0.5/0.55/0.7`$ 时 $`\mathrm{Im}\lambda = 0 / 1.4135 / 5.6539`$ ⟹ **$`\mathrm{Im}\lambda=0 \iff \beta=1/2`$** ✓ |
| ② ζ-cycle 圆长 | $`L=2\pi/s`$：$`\gamma_1\Rightarrow0.4445`$，$`\gamma_2\Rightarrow0.2989`$，$`\gamma_5\Rightarrow0.1908`$ ✓ |
| ③ $`\Sigma_\mu`$ 尺度不变 | $`\Sigma_\mu g(u_0)=\Sigma_\mu g(\mu u_0)=0.534478\ldots`$，**差 $`=0`$** ✓ |

### 2.7 ⚠️ 一处被核验「逼出来」的要点

核验③第一次**失败**（差 $`=1.0`$）。原因是取了 $`g(x)=e^{-x^2}`$，它**不满足 $`g(0)=0`$**，于是 $`k\to-\infty`$ 时 $`g(\mu^k u)\to g(0)=1\ne0`$，求和发散。

> 改用 $`g(x)=x^2e^{-x^2}`$ 后立即通过。
> ⟹ 这恰好验证了原文为什么要求 $`f\in\mathcal{S}^{\rm ev}_0`$（$`f(0)=0=\int f`$）——那个条件不是技术性修饰，而是 **$`\Sigma_\mu`$ 收敛的必要条件**。

### 2.9 结论：这条线走到哪了、还缺什么

> **它已完成第 ② 层（构造）：把零点实现为整体对象的谱。**

### 3.4 三处可精确化（非错误）

**① 有限性定理的准确形式。** 文章说「除去 $`\pi_n(S^n)`$、以及 $`n`$ 为偶数时 $`\pi_{2n-1}(S^n)`$ 这一个系列的例外，其余同伦群都是有限群」。准确如下：

$$\pi_n(S^n)\cong\mathbb Z;\qquad \pi_{2n-1}(S^n)\cong\mathbb Z\oplus\text{finite}\ \ (n\ \text{even});\qquad \text{otherwise}\ \pi_i(S^n)\ \text{finite}$$

即例外**只有上表两族**（同维 $`\pi_n(S^n)`$，与偶数维时的 $`\pi_{2n-1}(S^n)`$）；它们各含一个无穷循环直和项，是「有限群 ⊕ ℤ」，**不是「无限群」**。附带原文未提的真正技术：Serre 用的是**杀死同伦群**（killing homotopy groups）——逐层构造空间、消掉低阶同伦群，再用 Hurewicz 定理把同伦群读成同调群。**谱序列是工具，杀死是方法。**

**② 「27 岁」的精度。** ICM 1954 在阿姆斯特丹 **1954-09-02 至 09-09** 举行，Serre 生日是 **09-15**——**颁奖时实龄 26 岁**（差约一周满 27）。通行作「27 岁」（按年份计），**最年轻菲尔兹得主**这一结论完全不受影响。

**③ Serre 猜想的时间线（可再向前推）。** **1972-09** 致 Swinnerton-Dyer 的信（首次露面，1973 年印出）→ **1973-05-01** 致 **Tate** 的信 → **1973-07-02** Tate 回信**证出 p=2 情形** → **1987** Duke 论文（精确形式：level＝Artin 导子，weight＝Serre 权）。

### 3.5 原文未提、但值得补的两点

1. **FAC 的副产品——Quillen–Suslin 定理。** Serre 在 FAC 里顺口问了一个问题：*多项式环上的有限生成投射模，是否自由？* 这个「顺口之问」催生了交换代数一大片活动，**1976 年由 Quillen 与 Suslin 独立证成**（Quillen 因此获菲尔兹奖）。
2. **Serre 界（Serre bound）。** 精确形式是 $`|\#C(\mathbb F_q)-(q+1)|\le 2g\sqrt q`$——有**上界**，就有代数几何码的存在性边界。

### 3.6 方法论：三种「耐心」

| 耐心 | 形态 | 好在哪里 |
| :-- | :-- | :-- |
| **搭桥的耐心** | GAGA、Bass–Serre、Langlands | 不生产新对象，只**证明两套语言可对应** |
| **局部→整体的耐心** | 层与层上同调 | 把「每处有解」与「有整体解」之间的**缝**度量出来 |
| **无穷→有限的耐心** | 有限性定理、有限维上同调 | 从无穷张表里看出一条**可陈述的规律** |

以及一条朴素的行动建议（原文 §3）：**先找到感兴趣的问题，再学解决它所需要的理论**——与「先攒工具再找工作」的顺序**恰好相反**。

### 3.7 接口：接到体系（五点）

1. **「球面 ↔ 素数」＝ Langlands 的字面内容。** **Galois 表示（算术）↔ 自守/模形式（分析）** 是 Langlands 纲领的核心句式；**Serre 模性猜想是其中已被完全证明的一个特例**（2008–09）。
2. **「局部 ↔ 整体」＝ 本文缺的那件工具。** 层上同调把「局部处处可解、但整体不可解」的**障碍**量化成一个上同调群。Serre 定理的另一面就是——**「局部数据能否粘成整体」是一个可计算的量**。你缺的「把局部零点装成一个整体对象的构造」，在 Serre 的语言里就是问**某个上同调群是否消失**。
3. **「无穷 ↔ 有限」＝ 有限生成（而非有限）。** **Serre 定理（有限生成版）**：单连通空间的所有同伦群**有限生成**，当且仅当它的所有同调群**有限生成**。关键词不是「有限」，而是**有限生成**——它可能正落在「正性缺口」的下一层：**先证有限生成，再谈正性**。
4. **「数也是一种几何」＝ Bass–Serre 树。** $`\mathrm{PGL}_2(\mathbb Q_p)`$ 作用在 **Bruhat–Tits 树**上——「数系的内部长着几何」。
5. **「两套语言之间的桥」＝ 一元论的形态。** 文章最漂亮的一句：*「二十世纪数学里最深刻的发现，往往不是找到了新东西，而是找到两套语言之间可证明的联系。」* 这正是**一元两本账**的形态——**同一个量，两种记法**。

## 4. 接口：层上同调 ↔ 构造层缺口

> 方法：先算后说（脚本 `explore_sheaf_ss.py`，A/B/C 三验全绿）。

### 4.1 主张句

你缺的「**② 构造层**」——「把局部零点实现为某个整体对象的谱」——**在数学上有一个现成的机器形状：层上同调 ＋ 谱序列**。

层上同调**不生产**那个对象；它给出的是**把局部拼成整体**这件事本身的可计算形式：整体解 = $`H^0`$，粘合的**障碍** = 高阶上同调。于是「构造层缺口」被改写成一句可下手的话：

> **去找一个 site，使某个上同调群承载 ζ 的信息。**

### 4.2 层的语言：局部数据 → 整体解，障碍 = 上同调

- **层** $`\mathcal F`$：给每片开集配一组局部数据，并规定「限制到更小区域」的映射；
- 局部数据在重叠处一致，就能粘成整体数据——**粘成功的部分就是 $`H^0`$**；
- **粘不上的失败**，被高阶上同调**度量**出来。

一句话（严格）：**「每处附近有解」与「有整体解」之间的那道缝，宽窄由 $`H^{\ge1}`$ 给出。**

> 对照你的①层：①层说不缺，是因为在 ζ 的情形里「局部 ⟹ 整体」由**唯一延拓**保证——那是**一个**整体解存在；而层的语言问的是**更一般**的问题：**在什么条件下，一组局部数据能粘成整体？** 后一个问题（及其度量的 $`H^{\ge1}`$）正是②层的形状。

### 4.3 谱序列：把「局部 → 整体」变成逐级逼近

Leray 谱序列（纤维化 $`F\to E\to B`$）：

$$E_2^{p,q}=H^p(B;\mathcal H^q(F))\ \Rightarrow\ H^{p+q}(E)$$

原文那句比喻——「不正面攀爬崖壁，先搭一座逐级升高的平台」——就是它：**用底空间的上同调 ＋ 纤维的上同调，逐级拼出全空间的上同调。**

**算据 A（Hopf 纤维化 $`S^1\to S^3\to S^2`$）**：

- $`E_2`$ 的非零格 = `(0,0)`, `(2,0)`, `(0,1)`, `(2,1)`；
- 有**一个**微分 $`d_2:\ E_2^{0,1}\to E_2^{2,0}`$ 是同构；
- 它消掉 `(0,1)` 与 `(2,0)`，只剩 `(0,0)` 与 `(2,1)`；
- 对角线求和 ⟹ $`H^*(S^3)=(1,0,0,1)`$ ✓（与已知一致）。

**算据 B（对照：平凡积 $`S^1\times S^2`$）**：同一个底、同一个纤维，但谱序列**在 $`E_2`$ 退化**（无微分）⟹ $`H^*=H^*(S^2)\otimes H^*(S^1)=(1,1,1,1)`$ ✓。

> **结论（严格）**：**「整体」不是「底 ⊗ 纤维」的同义语**；差的正是**那个微分（扭曲 / 障碍）**。
> 这正是②层的要害：光有局部（纤维）与骨架（底）**不够**，缺的是把两者**扭转在一起的机制**。

### 4.4 对偶：上同调的「两本账」

**Serre 对偶**：

$$H^i(X,\mathcal F)^\vee\cong H^{n-i}\!\left(X,\ \mathcal F^\vee\otimes\omega_X\right)$$

特别地（$`\mathcal F=\mathcal O`$、光滑射影），它给出 **Betti 数回文**：$`h^i=h^{n-i}`$。

**算据 C**（皆回文）：

- `P^2`：1, 0, 1, 0, 1
- 亏格 2 曲线：1, 4, 1
- `P^1 x P^1`：1, 0, 2, 0, 1
- K3 曲面：1, 0, 22, 0, 1

⟹ 这正是「**一元两本账**」的原型：**同一组上同调，正读 / 反读（$`i\leftrightarrow n-i`$）逐条对齐。**

> **这也是③层「正性」进入的语言**：当对角 / 自交形式**定号**（Hodge 指标定理、Hodge 数 $`h^{p,q}`$ 的符号）时，上同调的维数与符号被**强制**——「定号 ⟹ 实谱」的代数原型。

### 4.5 三层缺口 ↔ 上同调的三个位置

| 你的层 | 内容 | 上同调语言里的对应 | 状态 |
| :-- | :-- | :-- | :-- |
| **① 信息层** | 局部 ⟹ 整体（唯一延拓） | $`H^0`$：整体解存在，且被局部数据锁定 | ✓ 不缺 |
| **② 构造层** | 把零点实现为整体对象（流 / 算子）的谱 | **存在一个 site，使某个上同调群承载 ζ** | ✗ 缺 |
| **③ 正性层** | 该对象自伴 / 正定 ⟹ 实谱 | **上同调群上带定号配对**（Weil 正性 / Sonin 投影） | ✗ 缺 |

> **严格的分界**：这张表是**框架对齐（结构性）**，**不是**「层上同调 ⟹ RH」。它只回答「②层缺的东西**长什么样**」，不回答「②层已被补上」。

### 4.6 三条路线，在层语言里的位置

| 路线 | 在层语言里 |
| :-- | :-- |
| **Connes** | **scaling site** $`\mathcal S=[0,\infty)\rtimes\mathbb N^\times`$ 上的**层上同调**实现临界零点（ζ-cycle = 圆 ＋ 尺度求和）—— **字面上就是「用层上同调造②层的对象」**（**限定**：以 $`\zeta(1/2+is)`$ 作商，实现**临界线零点**，不蕴含 RH。） |
| **Deninger** | 动态 / 整体上同调 ＋ 正则化行列式 $`\zeta=\det_{\mathrm{reg}}(s-\Theta)`$ |
| **Hesselholt** | THH 的 Tate 构造（$`TP`$）：同调机器在 Spec ℤ 上的版本 |

⟹ 三条路线**都在造②层**，且**都用了「局部→整体」的同调机器**。其中 **Connes 的 scaling site 是「②层已用层上同调实现」的最直接证据**。

### 4.7 可下手的一句话

> **找一个 site，使某个上同调群（或其上算子的谱）的零点集合 = ζ 的非平凡零点；再在此群上找到定号配对。**

前半句 = **②层**；后半句 = **③层**。这也让总纲那句「**缺的是正性，不是连接**」更精确：**②层的造法不止一种（Connes / Deninger / Hesselholt 各一），而③层的定号配对是公认未合的那一格。**

## 5. 核查：Scaling Site 层上同调 = ②层的定理级实现

> 算据：脚本 `verify_scaling_site.py`（A/B/C 三验全绿）。

### 5.1 结论先行

**核查结果：这条标注应当上调——从「半严格」改为「文献已证（②层构造完成，定理级）」。**

但同一批文献也**暴露出一个关键限定**，必须写进去：

> **该实现是以 $`\zeta(1/2+is)`$ 作商造出来的**——它**把「临界线」当作输入**，实现的是**临界线上（Hardy 已证存在）的那些零点**；
> 它**不**证明「所有零点都在临界线上」。**RH 的那一格（③层）丝毫未动。**

### 5.2 文献链（三篇）

### 5.3 ②层：把「实现」精确到定理

**对象与层**：

- **Site**：$`\mathscr S=[0,\infty)\rtimes\mathbb N^\times`$（半环化 topos；**点 ≅ adele class space**）；
- **结构层**：**整数斜率的凸分段仿射函数**层（tropical）；
- **用到的层**：$`\mathcal L^2`$（在 $`L=0`$ 消失的光滑截面），与由 $`\Sigma_\mu\mathcal E(f)`$ 生成的闭子层 $`\overline{\Sigma\mathcal E}`$。

**定理（文献所述）**：

> **Theorem 1.2 / 5.4**：$`H^0(\mathscr S,\ \mathcal L^2/\overline{\Sigma\mathcal E})`$ 上由 $`\mathbb R_+^*`$ 诱导的作用，同构于临界零点的谱实现——即 $`\lambda\mapsto\lambda^{is}`$ 作用在 $`\mathcal S(\mathbb R)/\overline{\mathcal S(\mathbb R)\zeta(1/2+is)}`$ 上。

**零点怎么被读出来**（命题 5.2 / 引理 5.3，文献所述）：

- $`H^0(\mathscr S,\mathcal L^2)\cong(C_0^\infty)^2`$，由 Fourier 分量 $`\hat\xi(L,\pm1)`$ 给出；
- 子层 $`\overline{\Sigma\mathcal E}`$ 对应由 $`\zeta(1/2\mp 2\pi i/L)`$ 生成的理想；
- 于是**当 $`L`$ 使该理想含零点时，对应 Fourier 分量落入被商掉的部分** ⟹ 零点表现为缩放作用的**指数 $`s`$**。

**coverings**：$`C_{\mu^n}\to C_\mu`$（$`n\in\mathbb N^\times`$）；ζ-cycle 在覆盖下稳定 ⟹ 同一零点在族中**无穷次**出现——这正是 site 成为「自然参数空间」的原因。

> ⟹ 与 §4.1 的②层定义逐字对齐：「存在一个 site，使某个上同调群承载 ζ 的信息」。

### 5.4 更强的一件事：scaling site 上真有 Riemann–Roch

对每个素数的周期轨道 $`C_p=\mathbb R_+^*/p^{\mathbb Z}`$（准热带曲线，Jacobi 椭圆曲线描述的变体），文献给出 theta 函数与 **Cartier 除数**理论，并证：

$$\mathrm{Dim}_{\mathbb R}\bigl(H^0(D)\bigr)-\mathrm{Dim}_{\mathbb R}\bigl(H^0(-D)\bigr)=\deg(D)$$

其中「维数」是**实值**的（type II 指标式）：

$$\mathrm{Dim}_{\mathbb R}(H^0(D))=\lim_{n\to\infty}p^{-n}\dim_{\mathrm{top}}\bigl(H^0(D)^{p^n}\bigr)$$

> ⟹ 这是 **Weil 函数域证明的几何核心（「RR ⟹ 正性」）在特征零的对应物**。
> 所以②层不只是「有一个谱实现」——它**已经带着 Weil 证法的那件关键工具**。

**自算复核**（`verify_scaling_site.py`）：

| 验 | 内容 | 结果 |
| :-- | :-- | :-- |
| **A** | 特征标单值下降要求 $`sL\in2\pi\mathbb Z`$，故圆长必为 $`2\pi/s`$ 的整数倍 | 前 4 个零点全部整数 ✓；非零点 `s'=13` 给出 0.9197（非整数）✓ |
| **B** | theta 恒等式 $`\theta(p\lambda)=\theta(\lambda)+\lambda-1`$ | `p=2,3,5,7` 最大偏差 ≤ 4.4e−16 ✓ |
| **C** | 覆盖稳定性：$`L\to nL`$ 仍满足 $`sL\in2\pi\mathbb Z`$ | `n=1..5` 全部整数 ✓ |

> **A 是这次「算出来」的亮点**：Theorem 1.1(ii) 说「长度是 $`2\pi/s`$ 整数倍的圆都是 ζ-cycle」——它其实等价于：**特征标 $`\lambda^{is}`$ 能在圆 $`\mathbb R_+^*/\mu^{\mathbb Z}`$ 上单值下降**。原文的陈述由此变成一句自明的算术。

### 5.5 ③层：不在这条路线里，且有一个关键限定

Theorem 1.2 里那个商，是**除以 $`\zeta(1/2+is)`$ 生成的理想**。也就是说：

- 它**不回答**「有没有零点不在临界线上」。

> ⟹ 用三层语言说：**它把②层做完了，但对③层是「零信息」。**
