# 三层标注：什么叫"严格 / 半严格 / 结构性"

数学文档的可信度不来自断言的数量，而来自**每条断言的证据等级**。
把不同等级混在一起，读者就无法判断哪条能引用。所以每份文档都要做这一层标注。

## 三个等级

### 严格
有**完整推导**或**已证定理**支撑，可复核、可引用。

- 例：`五行 = 子群 ⟨g²⟩`、`阴阳 = 商群 ℤ₁₀/⟨g²⟩`（群论可直接验算）；
- 例：`δF/δQ = 0` 给出泊肃叶流（Euler–Lagrange，一步可得）；
- 例：块反对角 Hessian 的核范数 `γ = 2‖D‖`。

### 半严格
有**数值或启发式**支撑，方向可信，但缺严格证明。

- 例：相变的临界点 `(1, 0.3455)`、γ 的数值 `65.6 / 249.4 / 361.6`；
- 例：Physarum 适应律收敛到最短路（数值 + 已知定理，但一般情形未证）。

### 结构性
是**框架内的结构性观察**，不是可证的等价。它有价值，但**不能当作定理引用**。

- 例："生克化通变对应泛函的五个结构项"——这是**配属**，不是等式；
- 例：两个不同领域的"精度"概念相似——这是**类比**，不是同一对象。

## 判定：问三个问题

1. **能不能写出一条可复核的推导链？** 能 → 严格。
2. **有没有数值/反例检查？** 有 → 至少半严格。
3. **它是在说"两个东西相等"，还是在说"两个东西相像/可以配属"？**
   后者 → 结构性（哪怕它看起来很像前者）。

## 常见误用（都真实发生过）

| 误用 | 问题 | 正确做法 |
| :-- | :-- | :-- |
| 直觉命名子群/商群（如"阴阳 = g⁵"） | 跳过逐元素验算 | 逐元素验算，再命名（正解是子群/商群） |
| 粗扫发现的"跳变" | 步长伪影 | **细扫**后再断言（γ 实为连续） |
| "适应律 = F 的梯度流" | 能量图景 ≠ 变分梯度 | 诚实写成"有效的能量图景（半严格）" |
| "γ_ren = c·η(0)" | 结构性冒充严格等价 | 验算后**否证**，或降级为"结构性直觉" |

## 在文档里怎么标注

- 表格式：在综述里给每条主张配一列"严格度"；
- 行内：在关键句后加括注 `（严格）` / `（半严格）` / `（结构性）`；
- **每份文档末尾**建议附一节"诚实标注"，汇总所有非严格结论。

> 标注的目的不是自我贬低，而是**让读者知道哪里可以站上去**。

## 与"订正"的配合

当你读解他人文档并发现错误时：
1. 先在第 2 步**算出来**（数值/推导）；
2. 在文档里**明确标注这是"订正"**，而非"补强"；
3. 给出新旧对照，让原作者能自行判断。
