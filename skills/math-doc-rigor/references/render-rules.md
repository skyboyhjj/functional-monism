# 渲染安全清单（GitHub MathJax + PDF 导出）

同一个 `.md` 既要能在 GitHub 网页端（MathJax）正确渲染，又要能导出 PDF。
下面每条规则都有过真实的失败案例，不是理论洁癖。

## 硬规则

### 1. 块公式用 `$$`，独立成行
```
$$
\gamma = \mathrm{Tr}(P^{1/2}) = \sum_i |\lambda_i|
$$
```
不要写成行内，也不要与正文同一行。

### 2. 数学环境内**零中文**
`$$...$$` 内部出现任何汉字，MathJax 会整体渲染失败。
需要中文说明就移出公式，或在公式外用文字写。
**自检命令会专门统计这一项，必须为 0。**

**为什么（机制）**：MathJax 对**拉丁数学字符**输出 `<path>`（矢量路径，任何渲染器都可靠）；
但对**没有数学字形的 CJK**，会退化成 `<text font-family="serif">且</text>`——**依赖系统字体**。
在 weasyprint 或缺该字体的 PDF 流水线里，这种 `<text>` 不可靠（甚至不显示）。
所以"数学环境零中文"不是洁癖，而是**换字体就崩**的硬约束。

### 3. 每行至多 1 个行内公式
一行里塞两个 `$...$` 会在某些渲染器下配对错乱。
需要并列就把句子拆成两行。

### 4. 行内公式用反引号写法
推荐：`` $`\gamma`$ ``
（反引号包裹 `$...$`，GitHub 与本地渲染都稳）。
**不要**用 `\(...\)`——GitHub 不渲染它。

### 5. 禁用风险宏
`\tag`、`\boxed`、`\overset`、`\underset`、`\xrightarrow`。
这些在 MathJax 的某些配置或 PDF 流水线里会坏。用等价写法替代：
- 上标标注 → 用 `^{(1)}`；
- 需要箭头 → 用 `\to`；
- 需要框 → 用加粗或另起一行。

### 6. 无裸 `<` / `>`
数学里的"小于"要写 `\le` / `<` 的正确 LaTeX 形式（`<` 在 HTML 里会被当成标签）。
用 `\lt` 或直接 `\le` / `\ge`。

### 7. 图片用 Markdown 内嵌 + 相对路径
```
![网络模型](figures/physarum_network.png)
```
- 路径**相对于文档所在目录**（与仓库布局一致）；
- PDF 导出时靠 `base_url` 解析，所以要确保图片真的在那个相对位置；
- 不要写绝对路径。

### 8. 交叉引用用 ASCII 名
引用别的文档时用仓库里的**英文文件名**（如 `axiom_IV_correspondence.md`），
不要用可能含特殊字符的标题。

### 9. 不混用旧写法
历史文档里偶见 `$`…`$` 被二次转换弄坏的行（如 `` 如 $`F`$` 的复杂度 ``）。
发现后**手工修复为纯文本或正确写法**，不要留着。

### 10. 禁用 emoji（字体栈里没有字形）

`md2pdf.py` 的字体栈是 `Noto Serif CJK SC → Noto Sans SC → DejaVu`，**不含 emoji 字体**。
`U+2705`（白重对勾）、`U+274C`（叉号）这类字符在 PDF 里会**直接消失**——不报错、不报警，静默丢内容。

- 表示"是/否"用 **`U+2713` / `U+2717`**（即对勾与叉，DejaVu 有字形），或直接写中文（"通过 / 未通过"）；
- 真要用 emoji，必须往 weasyprint 挂上 emoji 字体（如 Noto Color Emoji），否则别用。
- 非 emoji 的数学符号（`𝔽` `𝕊` `⟷` `⪰` `‖` `ζ`）在 Noto CJK / DejaVu 里**都有字形**，可以放心用。

### 11. 粗体 `**` 的 flanking 规则

CommonMark 只把 **能开** 的 `**` 当开定界符。**全角标点会破坏它**——典型翻车现场：

    是**「定号型」记账**      ← 错：开 `**` 后面紧跟「(Ps)，左定界判定失败，** 字面输出
    **是「定号型」记账**      ← 对：`**` 落在词首（前面是空格/行首）
    中文**粗体**中文          ← 可以：两侧都是汉字，flanking 成立

症状：PDF 里**字面出现两个星号**。修法就一句：**把 `**` 移到空格之后的词首**。
`check_md.py` 会按 flanking 规则模拟配对，把断裂处连同行号一起报出来。

## 自检

```bash
python3 scripts/check_md.py 文档.md
```

输出 `[ok]` 即通过；有 `[!]` 就按提示修，直到"合计隐患: 0"。
批量时把多个文件一次传入。

## 导出

```bash
MATHJAX_NODE_PATH=<node_modules 路径> python3 scripts/md2pdf.py --outdir pdf 文档.md
```

公式走 MathJax → 内嵌 SVG（保真）；脚本会为该文档报告"公式 n/n"（n 全渲染即保真）。
